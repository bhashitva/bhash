# भाष में प्रोग्रामिंग सीखें / Teach programming with Bhash

यह १२ पाठों का आरंभिक पाठ्यक्रम है। प्रत्येक पाठ लगभग ४५ मिनट का है;
समय विद्यार्थियों के अनुभव के अनुसार बदलें। पहले छह पाठों से शुरू करके
बाकी पाठ दूसरी इकाई में पढ़ाए जा सकते हैं। पहले से प्रोग्रामिंग जानना आवश्यक
नहीं है; देवनागरी पढ़ना और सामान्य अंकगणित उपयोगी है।

## शुरू कैसे करें

स्थापना के बिना [ब्राउज़र पाठशाला](https://play.bhashitva.org/) में पहले ११
पाठों की एक `.bhash` फ़ाइल का पूरा पाठ चिपकाएँ। पूरा कार्यक्रम देने पर
कार्यक्रम मोड चुनें, केवल कथन वाला मोड नहीं। इनपुट पहले भरें, फिर **चलाएँ**
दबाएँ। हर `पढ़ो()` के लिए एक पूर्णांक अलग पंक्ति में दें। ब्राउज़र चलने के
बीच में अगला इनपुट नहीं माँगता। पाठ १२ की बहु-फ़ाइल परियोजना स्थानीय VS Code/CLI में चलाएँ।

स्थानीय उपयोग में [VS Code extension](../editors/vscode/README.md) और JDK 17+
स्थापित करें। एक्सटेंशन में एक `.bhash` फ़ाइल खोलकर **Bhash: Run Project or File**
चलाएँ और JVM चुनें। स्रोत से कंपाइलर बनाने के लिए Maven भी चाहिए:

```sh
mvn package -DskipTests
java -jar target/bhash-compiler-0.1.0-SNAPSHOT.jar run lessons/03-decisions/example.bhash
```

यह और नीचे के आदेश रिपॉज़िटरी के मूल फ़ोल्डर से चलाएँ। पहले उदाहरण के लिए
`४` लिखें। संकलक ASCII और देवनागरी पूर्णांक इनपुट स्वीकारता है; संख्यात्मक
निर्गम देवनागरी में आता है। शून्य-चौड़ाई वाले अदृश्य अक्षरों से बचें और UTF-8 में सहेजें।

## हर पाठ का उपयोग

- `README.md`: उद्देश्य, पूर्वज्ञान, समयबद्ध योजना, चुनौती और मूल्यांकन।
- `example.bhash`: पहले पढ़ने और चलाने वाला पूरा उदाहरण।
- `challenge.bhash`: संकलित होने वाला अधूरा अभ्यास; परिणाम अभी सही नहीं होगा।
- `solution.bhash`: शिक्षक/विद्यार्थी के प्रयास के बाद देखने वाला समाधान।
- पाठ १२ में इन्हीं भूमिकाओं के लिए अलग परियोजना फ़ोल्डर हैं।

अकेली फ़ाइलों का प्रत्येक `मुख्य` स्वतंत्र है। पूरे `lessons` फ़ोल्डर को एक
संकलन इकाई न बनाएँ। समाधान सार्वजनिक हैं; मूल्यांकन में केवल अंतिम उत्तर
के बजाय अनुमान, कारण और नए परीक्षण भी पूछें।

## शिक्षक के लिए

[अवधारणा मानचित्र](concept-map.md) सीधे if/return/while जैसे प्रचलित अंग्रेज़ी
रूपों से जोड़ता है। [शिक्षक मार्गदर्शिका](teacher-guide.md) में संचालन, सहायता,
मूल्यांकन और Java/C# की ओर अगला कदम है। यह आरंभिक शिक्षण सामग्री है;
पूरा Java/C# पाठ्यक्रम या सभी भाष सुविधाओं का संदर्भ नहीं है।

## सामग्री की जाँच और योगदान

```sh
python scripts/check_lessons.py --target jvm
python scripts/check_lessons.py --target clr
```

दूसरे आदेश के लिए .NET 10 SDK चाहिए। दोनों लक्ष्य सभी उदाहरण/चुनौती/समाधान
संकलित करते हैं और उदाहरण तथा समाधान के परिणाम जाँचते हैं। CI Linux और
Windows पर दोनों लक्ष्य जाँचता है। ब्राउज़र बंडल उसी स्रोत से बनाया जा सकता है:

```sh
java -jar target/bhash-compiler-0.1.0-SNAPSHOT.jar compile lessons/06-recursion/solution.bhash --target wasm -o target/lesson-factorial-web
python3 -m http.server 8000 --bind 127.0.0.1 --directory target/lesson-factorial-web
```

फिर `http://localhost:8000/` खोलें। पूर्ण ब्राउज़र परीक्षण इस पाठ-जाँच का भाग
नहीं है; सभी पाठों पर ब्राउज़र परीक्षण का दावा नहीं किया जाता।

नया पाठ जोड़ते समय योजना, देवनागरी उदाहरण, अधूरा अभ्यास, समाधान और
`catalog.json` में स्पष्ट इनपुट/आउटपुट मामले दें। छोटे और सीमा वाले मामले
शामिल करें। [योगदान निर्देश](../CONTRIBUTING.md) भी देखें।
