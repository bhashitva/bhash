# १२. फ़ाइलें, संकुल और आयात

अवधि: ४५ मिनट। पूर्वज्ञान: पाठ ५; फ़ाइल और फ़ोल्डर बनाना।

## उद्देश्य और अंग्रेज़ी से सेतु

`संकुल` → package/namespace, `आयात` → import/using, `सार्वजनिक` → public।
कार्य को एक फ़ाइल में परिभाषित करके दूसरी से बुलाना सीखें। संकुल का नाम
घोषणा से आता है; फ़ोल्डर का नाम अपने आप संकुल नहीं बनाता।

## कक्षा की योजना

- ०–५ मिनट: चर्चा करें कि दो शिक्षक एक ही परियोजना की अलग फ़ाइलें कैसे लिखेंगे।
- ५–१५ मिनट: `example/bhash.project` और दोनों स्रोत फ़ाइलें पढ़ें।
- १५–२५ मिनट: उदाहरण परियोजना चलाएँ; परिणाम `२५` है। आयात और सार्वजनिक घोषणा ढूँढें।
- २५–४० मिनट: जोड़ी में चुनौती पूरी करें; एक विद्यार्थी गणित फ़ाइल, दूसरा मुख्य फ़ाइल समझाए।
- ४०–४५ मिनट: कार्य का नाम बदलकर संकलक की त्रुटि पढ़ें; फिर दोनों फ़ाइलों में नाम ठीक करें।

## चुनौती

`challenge/src/गणित/गणना.bhash` में `वर्गफल` कार्य पूरा करें। मुख्य कार्य
इनपुट पढ़कर उसका वर्ग छापता है। अभ्यास की संख्याएँ -१०० से १०० तक रखें।
`३` → `९`, `०` → `०`, `-४` → `१६`।

```sh
java -jar target/bhash-compiler-0.1.0-SNAPSHOT.jar run lessons/12-packages/challenge
```

आदेश रिपॉज़िटरी के मूल फ़ोल्डर से चलाएँ। `example`, `challenge` और `solution`
तीन अलग परियोजनाएँ हैं; पूरे `12-packages` फ़ोल्डर को एक परियोजना न मानें।

[संदर्भ समाधान](solution/src/गणित/गणना.bhash) प्रयास के बाद देखें।

## मूल्यांकन और विस्तार

विद्यार्थी तीन जाँच मामलों को सफल करे और समझाए कि आयात किस घोषणा तक पहुँचता है।
विस्तार: सार्वजनिक `घनफल` कार्य जोड़कर मुख्य फ़ाइल में आयात करें। फिर एक
सार्वजनिक वर्ग दूसरी फ़ाइल से आयात करने के लिए [मौजूदा बहु-फ़ाइल उदाहरण](../../examples/multi-file) देखें।
ये स्रोत आयात हैं; बाहरी प्रकाशित बाइनरी पैकेज डाउनलोड करने का प्रबंधक अभी नहीं है।
