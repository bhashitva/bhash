# HTTP / HTTPS से संपर्क (Networking)

इस संदर्भ ट्यूटोरियल में HTTP अनुरोध (Request), उत्तर (Response), शीर्ष (Headers),
सामग्री (Body), समयसीमा (Timeout), पुनर्निर्देशन (Redirect) और TLS प्रमाणपत्र की
जाँच के उदाहरण हैं। JVM, CLR और native Linux/Windows/macOS पर एक ही Bhash API
चलती है। सभी API अनुबंध और सीमाएँ [अंग्रेज़ी संदर्भ](../../docs/networking.md) में हैं।

## अनुरोध और उत्तर (Request and response)

`एचटीटीपी.पाओ` (GET) दिए पते से पूरा उत्तर प्राप्त करता है। स्थिति 404 या 500 भी
सामान्य HTTP उत्तर है; कनेक्शन या TLS विफल होने पर `अपवाद` मिलता है।

```bhash
आयात मानक.एचटीटीपी;
कार्य मुख्य() -> शून्य {
    प्रयास {
        स्थिर उ: मानक.एचटीटीपीउत्तर = एचटीटीपी.पाओ("https://example.com/");
        लिखो(उ.स्थिति());
        लिखो(उ.अंतिमपता());
        लिखो(उ.पाठ्यांश());
        लिखो(उ.सामग्री().आकार);
        प्रत्येक (व: पाठ में उ.शीर्षमान("Content-Type")) { लिखो(व); }
    } पकड़ो (ग: अपवाद) { लिखो(ग.संदेश); }
}
```

`स्थिति` (Status) संख्या लौटाता है। `अंतिमपता` (Final URI) पुनर्निर्देशन के बाद का
पता देता है। `पाठ्यांश` (UTF-8 text) सामग्री को सख्ती से UTF-8 मानकर पढ़ता है;
दूसरे एन्कोडिंग या अमान्य UTF-8 पर त्रुटि मिलती है। `सामग्री` (Bytes) मूल बाइटबफ़र
देता है। `शीर्षमान` (Header values) अक्षरों के बड़े/छोटे रूप का भेद किए बिना सभी
मानों की नई सूची देता है; शीर्ष न हो तो सूची खाली होती है। उत्तर पूरा बफ़र होता
है, इसलिए उत्तर पर `बंदकरो` बुलाने की आवश्यकता नहीं है।

## अनुरोध बनाना (Request builder)

`नया एचटीटीपीअनुरोध` (Request constructor) में विधि और पूरा पता दें।
`एचटीटीपी.भेजो` (Send) उस अनुरोध को चलाता है। नीचे `/echo` ऐसा अपना सर्वर होना
चाहिए जो भेजी गई सामग्री लौटाता हो; केवल उदाहरण का पता बदलें।

```bhash
आयात मानक.एचटीटीपी;
आयात मानक.एचटीटीपीअनुरोध;
कार्य मुख्य() -> शून्य {
    स्थिर अ: एचटीटीपीअनुरोध = नया एचटीटीपीअनुरोध("POST","http://127.0.0.1:8080/echo");
    अ.पाठरखो("नमस्ते, भारत😀");
    अ.शीर्षजोड़ो("X-Tag","first");
    अ.शीर्षजोड़ो("X-Tag","second");
    अ.शीर्षरखो("Content-Type","text/plain; charset=utf-8");
    अ.समयसीमा = ५०००;
    अ.अनुसरणसीमा = ३;
    स्थिर उ: मानक.एचटीटीपीउत्तर = एचटीटीपी.भेजो(अ);
    लिखो(उ.स्थिति(),उ.पाठ्यांश());
}
```

`पाठरखो` (Set text body) UTF-8 बाइट बनाता है और text/plain Content-Type रखता है।
`शीर्षजोड़ो` (Append header) उसी नाम के पहले मान हटाता नहीं है। `शीर्षरखो` (Replace
header) उसी नाम के सभी पुराने मान हटाता है। नाम case-insensitive हैं। CR/LF,
गैर-ASCII अनुरोध-शीर्ष और Host/Content-Length जैसे परिवहन-नियंत्रित शीर्ष अस्वीकार
होते हैं। जरूरत हो तो JSON सामग्री के बाद Content-Type बदलें:

```bhash
आयात मानक.एचटीटीपी;
आयात मानक.एचटीटीपीअनुरोध;
आयात मानक.जेसन;
कार्य मुख्य() -> शून्य {
    स्थिर अ: एचटीटीपीअनुरोध = नया एचटीटीपीअनुरोध("POST","http://127.0.0.1:8080/echo");
    स्थिर वस्तु: मानचित्र<पाठ,सर्ववस्तु> = नया मानचित्र<पाठ,सर्ववस्तु>{"नाम":"भारत😀"};
    अ.पाठरखो(जेसन.पाठबनाओ(वस्तु));
    अ.शीर्षरखो("Content-Type","application/json; charset=utf-8");
    स्थिर उत्तर: सर्ववस्तु = जेसन.पढ़ो(एचटीटीपी.भेजो(अ).पाठ्यांश());
    लिखो(जेसन.पाठबनाओ(उत्तर));
}
```

## बाइनरी सामग्री (Binary body)

`बाइटरखो` (Set bytes) बाइटबफ़र भेजता है; इसमें शून्य और 128–255 वाले बाइट भी
सुरक्षित रहते हैं। यह विधि अपना Content-Type निर्धारित नहीं करती।

```bhash
आयात मानक.एचटीटीपी;
आयात मानक.एचटीटीपीअनुरोध;
कार्य मुख्य() -> शून्य {
    स्थिर ब: बाइटबफ़र = नया बाइटबफ़र(३);
    ब[०] = परिवर्तित<बाइट>(०); ब[१] = परिवर्तित<बाइट>(१२८); ब[२] = परिवर्तित<बाइट>(२५५);
    स्थिर अ: एचटीटीपीअनुरोध = नया एचटीटीपीअनुरोध("PUT","http://127.0.0.1:8080/echo");
    अ.बाइटरखो(ब); अ.शीर्षरखो("Content-Type","application/octet-stream");
    स्थिर उ: मानक.एचटीटीपीउत्तर = एचटीटीपी.भेजो(अ);
    लिखो(उ.सामग्री().आकार);
}
```

अनुरोध और प्रत्येक उत्तर की सीमा 8 MiB है। यह पहला संस्करण streaming download
या अपने-आप gzip decompression नहीं करता। बड़ी फ़ाइलों के लिए बाद में अलग streaming
API चाहिए होगी।

## URI घटक कूटित करना (Percent encoding)

`कूटित` (Encode URI component) एक query मान या path segment को UTF-8 प्रतिशत
रूप में बदलता है। पूरे URL को इससे न बदलें, क्योंकि `/`, `:` और `?` भी कूटित होंगे।

```bhash
आयात मानक.एचटीटीपी;
कार्य मुख्य() -> शून्य {
    स्थिर खोज: पाठ = एचटीटीपी.कूटित("भारत + भाषा😀");
    लिखो("https://example.com/search?q="+खोज);
}
```

`समयसीमा` (Total timeout) डिफ़ॉल्ट 10,000 मिलीसेकंड है; इसमें सभी redirect hops
और उत्तर पढ़ने का समय सम्मिलित है। `अनुसरणसीमा` (Redirect limit) डिफ़ॉल्ट 5 है;
शून्य रखने पर मूल 3xx उत्तर वापस मिलता है। 301/302 पर POST, और 303 पर HEAD को
छोड़कर अन्य विधियाँ GET बनती हैं। 307/308 मूल विधि और सामग्री बनाए रखते हैं।

दूसरे origin पर जाते समय custom headers हटते हैं; गैर-GET/HEAD सामग्री दूसरे
origin पर अपने-आप नहीं भेजी जाती। HTTPS से HTTP downgrade अस्वीकार है। TLS 1.2+
में प्रमाणपत्र, hostname और अवधि हमेशा जाँची जाती है; इसे बंद करने का विकल्प नहीं है।

## उत्तर का परीक्षण (Response test double)

`एचटीटीपीउत्तर` (Response constructor) परीक्षण में सर्वर के बिना उत्तर बनाने देता है:

```bhash
आयात मानक.एचटीटीपीउत्तर;
आयात मानक.पाठ्य;
आयात मानक.परीक्षण;
कार्य मुख्य() -> शून्य {
    स्थिर उ: एचटीटीपीउत्तर = नया एचटीटीपीउत्तर(२००,"https://example.com/",नया सूची<पाठ>{"x-tag","one","X-Tag","two"},पाठ्य.यूटीएफ८("ठीक😀"));
    परीक्षण.बराबर(२००,उ.स्थिति()); परीक्षण.बराबर("ठीक😀",उ.पाठ्यांश());
    परीक्षण.बराबर(२,उ.शीर्षमान("x-tag").आकार);
}
```

पूरा CLI उदाहरण [client.bhash](../../examples/networking/client.bhash) में है;
`--url=https://example.com/` से उसका पता बदल सकते हैं। नेटवर्क के बिना चलने वाला
परीक्षण [validation.test.bhash](../../examples/networking/validation.test.bhash) है।
ब्राउज़र runner में अभी तुल्यकालिक HTTP असमर्थित है; `भेजो`/`पाओ` स्पष्ट अपवाद
देते हैं और fetch नहीं करते। वहाँ आगे asynchronous API और host/CORS नीति चाहिए।

अनुरोध के `विधि`, `पता`, `समयसीमा`, `अनुसरणसीमा`, `शीर्ष` और `सामग्री` क्षेत्र
बदले जा सकते हैं। उदाहरण के लिए `अ.विधि = "PATCH";` और `अ.पता = "https://example.com/api";`।
सीधे शीर्ष सूची बदलने पर भी `भेजो` उसकी संरचना और मान फिर जाँचता है।
