## अपवाद सँभालना (Exception Handling)

बाहरी पाठ, गलत सीमा, अमान्य दिनांक और सामान्य I/O failures पर `अपवाद` पकड़ा जा सकता है। पहले से जाँची गई गलत परिस्थिति को कभी सफल परिणाम न मानें। वास्तविक संदेश पढ़ने के लिए `गलती.संदेश` उपलब्ध है। संदेश का ठीक पाठ targets के बीच बदल सकता है, इसलिए test में अपना निश्चित संदेश देना उपयोगी है।

```bhash
आयात मानक.गणित;
कार्य मुख्य() -> शून्य {
    प्रयास {
        लिखो(गणित.वर्गमूल(-१.०));
    } पकड़ो (गलती: अपवाद) {
        लिखो("वर्गमूल के लिए गैर-ऋणात्मक मान दें।");
    }
}
```

इसका आउटपुट `वर्गमूल के लिए गैर-ऋणात्मक मान दें।` है। पूरा errors उदाहरण गलत slice, खाली separator, ऋणात्मक repetition, formatting की सीमा, integer overflow, math domain, random bounds, duplicate JSON keys, JSON में गलत अंक, cyclic collections, गलत दिनांक और अमान्य UTF-8 की जाँच करता है।

हर गलती runtime exception नहीं है। `गणित.वर्गमूल(८१)` में गलत **पूर्णांक** argument देने पर compilation रुकती है; `प्रयास` उसे नहीं पकड़ सकता। सही decimal call `गणित.वर्गमूल(८१.०)` है। fatal host allocation/process failures को recoverable library errors न मानें।

## JSON से माप लेकर परिणाम दिखाना (Parse, Calculate and Format)

JSON से मिले दशमलव मापों पर गणना करें, फिर मनचाहे स्थानों तक परिणाम दिखाएँ। JSON numbers और `संख्यापाठ` का पाठ ASCII में है; आखिरी चरण में चाहें तो अंकों को देवनागरी बनाएँ।

```bhash
आयात मानक.जेसन;
आयात मानक.पाठ्य;
कार्य मुख्य() -> शून्य {
    स्थिर माप: मानचित्र<पाठ,सर्ववस्तु> = परिवर्तित<मानचित्र<पाठ,सर्ववस्तु>>(जेसन.पढ़ो("{\"लंबाई\":5.7,\"चौड़ाई\":4.2}"));
    स्थिर लंबाई: दशमलव = परिवर्तित<दशमलव>(माप["लंबाई"]);
    स्थिर चौड़ाई: दशमलव = परिवर्तित<दशमलव>(माप["चौड़ाई"]);
    लिखो("क्षेत्रफल = " + पाठ्य.अंकदेवनागरी(पाठ्य.संख्यापाठ(लंबाई * चौड़ाई, २)));
}
```

अपेक्षित आउटपुट `क्षेत्रफल = २३.९४` है। वास्तविक बाहरी JSON में आवश्यक keys और मानों के प्रकार पहले जाँचें; इस नियंत्रित उदाहरण में दोनों ज्ञात हैं।

## छोटे दशमलव अंतर की तुलना (Floating-Point Tolerance)

प्राकृतिक लघुगणक, exponential और त्रिकोणमितीय परिणामों को सामान्यतः आखिरी bit तक समान न मानें। एक स्पष्ट tolerance तय करें।

```bhash
आयात मानक.गणित;
कार्य मुख्य() -> शून्य {
    स्थिर अंतर: दशमलव = गणित.निरपेक्ष(गणित.लघुगणक(गणित.घातांक(१.०)) - १.०);
    लिखो(अंतर < ०.०००००१);
}
```

इस उदाहरण में `सत्य` अपेक्षित है। अलग समस्याओं के माप और अपेक्षित सटीकता के अनुसार tolerance चुनें; ०.०००००१ हर समस्या का सार्वभौमिक नियम नहीं है।

## एक नाम, अलग काम (Namespacing and Aliases)

`पाठ्य.अंश` slice निकालता है; `यादृच्छिक.अंश` random fraction देता है। module नाम इस अंतर को स्पष्ट करता है। alias छोटे लेकिन समझने योग्य रखें।

```bhash
आयात मानक.पाठ्य उपनाम प;
आयात मानक.यादृच्छिक उपनाम य;
कार्य मुख्य() -> शून्य {
    य.बीज(१);
    लिखो(प.अंश("ABCD", १, ३));
    स्थिर संख्या: दशमलव = य.अंश();
    लिखो(संख्या >= ०.० && संख्या < १.०);
}
```

आउटपुट `BC` और अगली पंक्ति में `सत्य` है। इन नामों को global `अंश` के साथ भ्रमित न करें।

## फ़ाइल क्षमता और failure (Capability Check and I/O Errors)

क्षमता उपलब्ध होने पर भी कोई विशेष operation विफल हो सकती है। इस उदाहरण में browser पर unsupported branch चलता है; desktop पर खाली पथ की गलती पकड़ी जाती है। यह कोई वास्तविक फ़ाइल नहीं लिखता।

```bhash
आयात मानक.फ़ाइल;
कार्य मुख्य() -> शून्य {
    यदि (!फ़ाइल.समर्थित()) {
        लिखो("इस browser में फ़ाइल API उपलब्ध नहीं है।");
        लौटाओ;
    }
    प्रयास {
        फ़ाइल.पाठपढ़ो("");
    } पकड़ो (गलती: अपवाद) {
        लिखो("फ़ाइल पथ मान्य नहीं है।");
    }
}
```

## याद रखने योग्य सीमाएँ (Limits and Boundaries)

| विषय | अनुबंध |
| --- | --- |
| scalar indexing | शून्य-आधारित; slice की अंत सीमा शामिल नहीं |
| text repetition | परिणाम अधिकतम १,०४८,५७६ UTF-16 code units |
| fixed formatting | ०–१५ fractional places; ties-to-even |
| integer random | निम्न शामिल, ऊपरी शामिल नहीं; धनात्मक signed 64-bit span |
| JSON | input/output अधिकतम १,०४८,५७६ UTF-16 code units; recursive depth ६४ |
| dates | वर्ष 0001–9999; ठीक तीन milliseconds digits और UTC Z |
| files | पढ़ने/लिखने की सीमा १६ MiB; parent directory पहले चाहिए |

इन APIs में networking, streaming, async I/O, local timezone conversion, Unicode case folding, exact decimal arithmetic या browser file-picker नहीं है। वे अलग सुविधाएँ होंगी। अभी उपलब्ध फ़ंक्शन के अर्थ को उस संभावित भविष्य के व्यवहार से न मिलाएँ।
