# संख्यात्मक गणना (Mathematics)

यह पूरा module experimental native Linux x86-64 target पर भी उपलब्ध है। [Native व्यवहार, errors और cross-target जाँच](../../docs/native-math-random.md) देखें।

गणित के फ़ंक्शन finite संख्याओं पर काम करते हैं। पूर्णांक और दशमलव अलग प्रकार हैं: दशमलव पैरामीटर के लिए २.० लिखें, २ नहीं। यहाँ दशमलव परिणाम को स्थिर ढंग से दिखाने के लिए पाठ्य.संख्यापाठ इस्तेमाल किया गया है; यह गणित की मूल गणना को नहीं बदलता।

[मानक पुस्तकालय का सूचकांक](README.md) · [पूरा चलाने योग्य उदाहरण](examples/02-math.bhash) · [पूरे उदाहरण का अपेक्षित आउटपुट](examples/02-math.expected.txt)

नीचे हर छोटा कोड-खंड अलग उदाहरण है। उसे इस ढाँचे में मुख्य() के भीतर रखें; एक साथ सभी उदाहरण चलाने के लिए ऊपर दी गई पूरी फ़ाइल प्रयोग करें।

```bhash
आयात मानक.गणित;
आयात मानक.पाठ्य;
कार्य मुख्य() -> शून्य {
    // नीचे दिए गए किसी एक उदाहरण का कोड यहाँ रखें।
}
```

<a id="absolute-value-abs"></a>

## निरपेक्ष (Absolute Value / Abs)

संख्या का ऋण-चिह्न हटाकर उसका परिमाण लौटाता है। पूर्णांक और दशमलव के अलग ओवरलोड हैं; जिस प्रकार का इनपुट है, उसी प्रकार का परिणाम मिलता है।

**हस्ताक्षर:**

- `गणित.निरपेक्ष(मानक: पूर्णांक) → पूर्णांक`
- `गणित.निरपेक्ष(मानक: दशमलव) → दशमलव`

```bhash
लिखो(गणित.निरपेक्ष(-७));
लिखो(पाठ्य.संख्यापाठ(गणित.निरपेक्ष(-७.५), १));
```

**अपेक्षित आउटपुट:**

```text
७
7.5
```

सबसे छोटे signed 64-bit पूर्णांक -९२२३३७२०३६८५४७७५८०८ का धनात्मक परिमाण पूर्णांक में नहीं समाता; उस पर अपवाद आता है।

<a id="minimum-min"></a>

## न्यूनतम (Minimum / Min)

दो मानों में छोटा मान लौटाता है। दोनों पूर्णांक हों या दोनों दशमलव हों; यह अपने-आप मिश्रित प्रकारों को नहीं बदलता।

**हस्ताक्षर:**

- `गणित.न्यूनतम(क: पूर्णांक, ख: पूर्णांक) → पूर्णांक`
- `गणित.न्यूनतम(क: दशमलव, ख: दशमलव) → दशमलव`

```bhash
लिखो(गणित.न्यूनतम(७, २));
लिखो(पाठ्य.संख्यापाठ(गणित.न्यूनतम(७.५, २.२५), २));
```

**अपेक्षित आउटपुट:**

```text
२
2.25
```

दोनों मान बराबर हों तो वही मान मिलता है। दशमलव इनपुट finite होने चाहिए।

<a id="maximum-max"></a>

## अधिकतम (Maximum / Max)

दो मानों में बड़ा मान लौटाता है। ऊपरी सीमा, सर्वश्रेष्ठ अंक या सबसे बड़ा माप चुनने में उपयोगी है।

**हस्ताक्षर:**

- `गणित.अधिकतम(क: पूर्णांक, ख: पूर्णांक) → पूर्णांक`
- `गणित.अधिकतम(क: दशमलव, ख: दशमलव) → दशमलव`

```bhash
लिखो(गणित.अधिकतम(-१, २));
लिखो(पाठ्य.संख्यापाठ(गणित.अधिकतम(-१.५, २.२५), २));
```

**अपेक्षित आउटपुट:**

```text
२
2.25
```

पूर्णांक और दशमलव दोनों के ओवरलोड हैं। यह सूची के सारे तत्व अपने-आप नहीं जाँचता; उसके लिए क्रम से तत्वों की तुलना करें।

<a id="square-root-sqrt"></a>

## वर्गमूल (Square Root / Sqrt)

गैर-ऋणात्मक दशमलव का वर्गमूल लौटाता है। परिणाम दशमलव होता है, भले ही गणितीय उत्तर पूर्ण संख्या हो।

**हस्ताक्षर:**

- `गणित.वर्गमूल(मानक: दशमलव) → दशमलव`

```bhash
लिखो(पाठ्य.संख्यापाठ(गणित.वर्गमूल(८१.०), २));
```

**अपेक्षित आउटपुट:**

```text
9.00
```

ऋणात्मक मान पर वास्तविक वर्गमूल उपलब्ध नहीं है, इसलिए अपवाद आता है। ८१ जैसा पूर्णांक देने के स्थान पर ८१.० दें।

<a id="power-pow"></a>

## घात (Power / Pow)

आधार को दी गई घात तक उठाता है। दोनों पैरामीटर दशमलव हैं; परिणाम भी दशमलव है।

**हस्ताक्षर:**

- `गणित.घात(आधारक: दशमलव, घातक: दशमलव) → दशमलव`

```bhash
लिखो(पाठ्य.संख्यापाठ(गणित.घात(२.०, १०.०), १));
```

**अपेक्षित आउटपुट:**

```text
1024.0
```

डोमेन से बाहर का परिणाम, जैसे ऋणात्मक आधार की असंगत भिन्न घात, या non-finite overflow अपवाद देता है। यह arbitrary-precision पूर्णांक घात नहीं है।

<a id="floor"></a>

## फर्श (Floor)

संख्या से बड़ा न होने वाला निकटतम पूर्ण-मूल्य वाला दशमलव लौटाता है। ऋणात्मक मानों पर यह शून्य की ओर काटने से अलग है।

**हस्ताक्षर:**

- `गणित.फर्श(मानक: दशमलव) → दशमलव`

```bhash
लिखो(पाठ्य.संख्यापाठ(गणित.फर्श(२.७), १));
लिखो(पाठ्य.संख्यापाठ(गणित.फर्श(-२.७), १));
```

**अपेक्षित आउटपुट:**

```text
2.0
-3.0
```

परिणाम का प्रकार दशमलव रहता है; यह पूर्णांक में cast करने का फ़ंक्शन नहीं है।

<a id="ceiling-ceil"></a>

## छत (Ceiling / Ceil)

संख्या से छोटा न होने वाला निकटतम पूर्ण-मूल्य वाला दशमलव लौटाता है।

**हस्ताक्षर:**

- `गणित.छत(मानक: दशमलव) → दशमलव`

```bhash
लिखो(पाठ्य.संख्यापाठ(गणित.छत(२.२), १));
लिखो(पाठ्य.संख्यापाठ(गणित.छत(-२.२), १));
```

**अपेक्षित आउटपुट:**

```text
3.0
-2.0
```

फ़ंक्शन का वास्तविक नाम छत है। परिणाम दशमलव है और दिशा धनात्मक अनंत की ओर है।

<a id="round-to-nearest-ties-to-even"></a>

## निकटतम (Round to Nearest / Ties to Even)

निकटतम पूर्ण-मूल्य वाले दशमलव तक round करता है। ठीक बीच में होने पर सम पूर्णांक चुना जाता है।

**हस्ताक्षर:**

- `गणित.निकटतम(मानक: दशमलव) → दशमलव`

```bhash
लिखो(पाठ्य.संख्यापाठ(गणित.निकटतम(२.५), १));
लिखो(पाठ्य.संख्यापाठ(गणित.निकटतम(३.५), १));
```

**अपेक्षित आउटपुट:**

```text
2.0
4.0
```

यह हमेशा .५ को ऊपर नहीं करता। तय दशमलव स्थानों वाला पाठ चाहिए तो पाठ्य.संख्यापाठ अलग कार्य है।

<a id="sine-sin"></a>

## ज्या (Sine / Sin)

रेडियन में दिए गए कोण की sine लौटाता है। यदि कोण degrees में हो, तो पहले degrees × पाई() / १८०.० करें।

**हस्ताक्षर:**

- `गणित.ज्या(मानक: दशमलव) → दशमलव`

```bhash
लिखो(पाठ्य.संख्यापाठ(गणित.ज्या(गणित.पाई() / २.०), ३));
```

**अपेक्षित आउटपुट:**

```text
1.000
```

त्रिकोणमितीय परिणाम binary64 में अनुमानित हो सकते हैं। nontrivial परिणामों के लिए सीधे बराबरी की जगह सहनशीलता वाली तुलना करें।

<a id="cosine-cos"></a>

## कोज्या (Cosine / Cos)

रेडियन में दिए गए कोण की cosine लौटाता है। शून्य रेडियन का cosine एक है।

**हस्ताक्षर:**

- `गणित.कोज्या(मानक: दशमलव) → दशमलव`

```bhash
लिखो(पाठ्य.संख्यापाठ(गणित.कोज्या(०.०), ३));
```

**अपेक्षित आउटपुट:**

```text
1.000
```

इनपुट degrees में नहीं है। अलग targets के अंतिम binary64 bits में छोटा अंतर हो सकता है।

<a id="natural-logarithm-log"></a>

## लघुगणक (Natural Logarithm / Log)

धनात्मक दशमलव का प्राकृतिक लघुगणक, अर्थात आधार e वाला logarithm, लौटाता है। यह आधार १० वाला log नहीं है।

**हस्ताक्षर:**

- `गणित.लघुगणक(मानक: दशमलव) → दशमलव`

```bhash
लिखो(पाठ्य.संख्यापाठ(गणित.लघुगणक(१.०), ३));
लिखो(पाठ्य.संख्यापाठ(गणित.लघुगणक(गणित.घातांक(१.०)), ३));
```

**अपेक्षित आउटपुट:**

```text
0.000
1.000
```

इनपुट ० या ऋणात्मक हो तो अपवाद आता है। अन्य आधार का log चाहिए तो log(x) / log(base) का उपयोग करें और दोनों के डोमेन जाँचें।

<a id="exponential-exp"></a>

## घातांक (Exponential / Exp)

e को दिए गए दशमलव मान की घात तक उठाता है। प्राकृतिक लघुगणक का विपरीत संबंध समझने में उपयोगी है।

**हस्ताक्षर:**

- `गणित.घातांक(मानक: दशमलव) → दशमलव`

```bhash
लिखो(पाठ्य.संख्यापाठ(गणित.घातांक(०.०), ३));
लिखो(पाठ्य.संख्यापाठ(गणित.घातांक(१.०), ३));
```

**अपेक्षित आउटपुट:**

```text
1.000
2.718
```

बहुत बड़ा इनपुट non-finite overflow पैदा करे तो अपवाद आता है। बहुत छोटे परिणाम binary64 में शून्य तक underflow हो सकते हैं।

<a id="pi"></a>

## पाई (Pi)

वृत्त के स्थिरांक π का binary64 अनुमान लौटाता है। यह बिना पैरामीटर वाला फ़ंक्शन है, इसलिए कोष्ठक आवश्यक हैं।

**हस्ताक्षर:**

- `गणित.पाई() → दशमलव`

```bhash
लिखो(पाठ्य.संख्यापाठ(गणित.पाई(), ६));
```

**अपेक्षित आउटपुट:**

```text
3.141593
```

यह अनंत अंकों वाला exact मान नहीं है। कोणों और वृत्त की गणनाओं में दशमलव सीमाएँ ध्यान में रखें।
