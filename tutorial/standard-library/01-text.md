# पाठ के साथ काम (Text and Strings)

पाठ केवल अक्षरों की दिखाई देने वाली संख्या नहीं है। भाष यहाँ Unicode scalar values के अनुसार लंबाई और स्थान गिनती है। स्थान शून्य से शुरू होते हैं; मात्राएँ अलग scalar हो सकती हैं। खोज अक्षरशः होती है; अपने-आप Unicode normalization या नियमित अभिव्यक्ति लागू नहीं होती।

[मानक पुस्तकालय का सूचकांक](README.md) · [पूरा चलाने योग्य उदाहरण](examples/01-text.bhash) · [पूरे उदाहरण का अपेक्षित आउटपुट](examples/01-text.expected.txt)

नीचे हर छोटा कोड-खंड अलग उदाहरण है। उसे इस ढाँचे में मुख्य() के भीतर रखें; एक साथ सभी उदाहरण चलाने के लिए ऊपर दी गई पूरी फ़ाइल प्रयोग करें।

```bhash
आयात मानक.पाठ्य;
कार्य मुख्य() -> शून्य {
    // नीचे दिए गए किसी एक उदाहरण का कोड यहाँ रखें।
}
```

<a id="length"></a>

## लंबाई (Length)

पाठ में Unicode scalar values की संख्या लौटाता है। इमोजी के लिए UTF-16 के दो code units होने पर भी उसे एक scalar गिना जाता है। देवनागरी की मात्रा अलग scalar है; इसलिए यह दिखाई देने वाले अक्षरों या grapheme clusters की गिनती नहीं है।

**हस्ताक्षर:**

- `पाठ्य.लंबाई(मानक: पाठ) → पूर्णांक`

```bhash
लिखो(पाठ्य.लंबाई("क😀ख"));
लिखो(पाठ्य.लंबाई("कि"));
```

**अपेक्षित आउटपुट:**

```text
३
२
```

खाली पाठ की लंबाई ० है। स्थानों की गणना करते समय इसी फ़ंक्शन की परिभाषा अपनाएँ।

<a id="substring-slice"></a>

## अंश (Substring / Slice)

आरंभ से अंत के ठीक पहले तक का पाठ देता है। आरंभ शामिल है और अंत शामिल नहीं है। मूल पाठ नहीं बदलता।

**हस्ताक्षर:**

- `पाठ्य.अंश(मानक: पाठ, आरंभ: पूर्णांक, अंत: पूर्णांक) → पाठ`

```bhash
लिखो(पाठ्य.अंश("a😀भारत", १, २));
लिखो(पाठ्य.अंश("ABCD", १, ३));
```

**अपेक्षित आउटपुट:**

```text
😀
BC
```

० ≤ आरंभ ≤ अंत ≤ लंबाई होना चाहिए। बराबर आरंभ और अंत पर खाली पाठ मिलता है; गलत सीमा पर पकड़ने योग्य अपवाद आता है।

<a id="index-of-find"></a>

## खोजो (Index Of / Find)

खोजे गए पाठ की पहली उपस्थिति का शून्य-आधारित scalar स्थान देता है। पाठ न मिले तो -१ लौटता है।

**हस्ताक्षर:**

- `पाठ्य.खोजो(मानक: पाठ, खोज: पाठ) → पूर्णांक`

```bhash
लिखो(पाठ्य.खोजो("a😀भारत", "भारत"));
लिखो(पाठ्य.खोजो("भारत", "XYZ"));
लिखो(पाठ्य.खोजो("भारत", ""));
```

**अपेक्षित आउटपुट:**

```text
२
-१
०
```

खाली खोज ० पर मिलती है। परिणाम को अंश में देने से पहले -१ की जाँच करें।

<a id="contains"></a>

## है (Contains)

बताता है कि छोटा पाठ बड़े पाठ के किसी भाग में मौजूद है या नहीं। यह पूरे शब्द की खोज नहीं है और case-sensitive है।

**हस्ताक्षर:**

- `पाठ्य.है(मानक: पाठ, खोज: पाठ) → तार्किक`

```bhash
लिखो(पाठ्य.है("भारत", "रत"));
लिखो(पाठ्य.है("भारत", ""));
लिखो(पाठ्य.है("ABC", "abc"));
```

**अपेक्षित आउटपुट:**

```text
सत्य
सत्य
असत्य
```

खाली खोज हमेशा मिलती है। यदि खाली इनपुट अस्वीकार करना हो, तो पहले उसकी लंबाई जाँचें; Chess के मोहरे की जाँच में यह महत्वपूर्ण है।

<a id="starts-with"></a>

## आरंभ (Starts With)

जाँचता है कि पाठ दिए गए prefix से शुरू होता है या नहीं। फ़ाइल नाम, संकेत या आदेश पहचानने में उपयोगी है।

**हस्ताक्षर:**

- `पाठ्य.आरंभ(मानक: पाठ, खोज: पाठ) → तार्किक`

```bhash
लिखो(पाठ्य.आरंभ("नमस्ते भारत", "नमस्ते"));
लिखो(पाठ्य.आरंभ("report.txt", "REPORT"));
```

**अपेक्षित आउटपुट:**

```text
सत्य
असत्य
```

खाली prefix के लिए सत्य मिलता है। यह case-sensitive, अक्षरशः तुलना है।

<a id="ends-with"></a>

## अंत (Ends With)

जाँचता है कि पाठ दिए गए suffix पर समाप्त होता है या नहीं। एक्सटेंशन पहचानना इसका एक सामान्य उपयोग है।

**हस्ताक्षर:**

- `पाठ्य.अंत(मानक: पाठ, खोज: पाठ) → तार्किक`

```bhash
लिखो(पाठ्य.अंत("कार्यक्रम.bhash", ".bhash"));
लिखो(पाठ्य.अंत("कार्यक्रम.bhash", ".txt"));
```

**अपेक्षित आउटपुट:**

```text
सत्य
असत्य
```

खाली suffix पर सत्य मिलता है। केवल suffix मिलने से कोई पथ सुरक्षित या वैध फ़ाइल नहीं बन जाता।

<a id="replace"></a>

## बदलो (Replace)

पुराने पाठ की सभी अक्षरशः उपस्थितियाँ नए पाठ से बदलकर नया पाठ लौटाता है। मूल मान अपरिवर्तित रहता है।

**हस्ताक्षर:**

- `पाठ्य.बदलो(मानक: पाठ, पुराना: पाठ, नवीन: पाठ) → पाठ`

```bhash
लिखो(पाठ्य.बदलो("क.*ख.*ग", ".*", " + "));
```

**अपेक्षित आउटपुट:**

```text
क + ख + ग
```

पुराना पाठ खाली नहीं हो सकता। यहाँ .* का अर्थ दो वास्तविक चिह्न हैं, regex नहीं; नया पाठ खाली देकर मिला हुआ भाग हटाया जा सकता है।

<a id="split"></a>

## बाँटो (Split)

अक्षरशः विभाजक के अनुसार पाठ को सूची<पाठ> में बाँटता है। बीच और अंत के खाली हिस्से भी बचाए जाते हैं।

**हस्ताक्षर:**

- `पाठ्य.बाँटो(मानक: पाठ, विभाजक: पाठ) → सूची<पाठ>`

```bhash
स्थिर भाग: सूची<पाठ> = पाठ्य.बाँटो("क,,ख,", ",");
लिखो(भाग.आकार);
लिखो("[" + पाठ्य.जोड़ो(भाग, "|") + "]");
```

**अपेक्षित आउटपुट:**

```text
४
[क||ख|]
```

विभाजक खाली नहीं हो सकता और regex नहीं है। कई खाली स्थानों को अपने-आप एक विभाजक नहीं माना जाता।

<a id="join"></a>

## जोड़ो (Join)

सूची के सभी पाठों के बीच विभाजक रखकर एक पाठ बनाता है। यह Split का उपयोगी साथी है।

**हस्ताक्षर:**

- `पाठ्य.जोड़ो(मानक: सूची<पाठ>, विभाजक: पाठ) → पाठ`

```bhash
स्थिर शब्द: सूची<पाठ> = नया सूची<पाठ>{"भाष", "भारत", "ज्ञान"};
लिखो(पाठ्य.जोड़ो(शब्द, " · "));
```

**अपेक्षित आउटपुट:**

```text
भाष · भारत · ज्ञान
```

इसका पैरामीटर सूची<पाठ> है, सरणी नहीं। खाली सूची से खाली पाठ मिलता है; विभाजक खाली हो सकता है।

<a id="trim"></a>

## छाँटो (Trim)

पाठ के दोनों सिरों से Unicode White_Space समूह के खाली स्थान हटाता है। बीच के स्थान नहीं बदलते।

**हस्ताक्षर:**

- `पाठ्य.छाँटो(मानक: पाठ) → पाठ`

```bhash
लिखो("[" + पाठ्य.छाँटो("\t  नमस्ते भारत  \n") + "]");
```

**अपेक्षित आउटपुट:**

```text
[नमस्ते भारत]
```

NBSP जैसे Unicode खाली स्थान भी हटते हैं। सभी अदृश्य चिह्न White_Space नहीं हैं; यह सामान्य Unicode normalization नहीं करता।

<a id="to-upper-case"></a>

## बड़ाअक्षर (To Upper Case)

केवल ASCII a–z को A–Z में बदलता है। अन्य scalars, जिनमें देवनागरी और इमोजी शामिल हैं, वैसे ही रहते हैं।

**हस्ताक्षर:**

- `पाठ्य.बड़ाअक्षर(मानक: पाठ) → पाठ`

```bhash
लिखो(पाठ्य.बड़ाअक्षर("e2 हिन्दी 😀"));
```

**अपेक्षित आउटपुट:**

```text
E2 हिन्दी 😀
```

यह सभी भाषाओं की Unicode case mapping नहीं है। Chess coordinates जैसे ASCII संकेतों के लिए इसका व्यवहार निश्चित है।

<a id="to-lower-case"></a>

## छोटाअक्षर (To Lower Case)

केवल ASCII A–Z को a–z में बदलता है। देवनागरी पाठ पर कोई case परिवर्तन नहीं होता।

**हस्ताक्षर:**

- `पाठ्य.छोटाअक्षर(मानक: पाठ) → पाठ`

```bhash
लिखो(पाठ्य.छोटाअक्षर("HELLO हिन्दी"));
```

**अपेक्षित आउटपुट:**

```text
hello हिन्दी
```

यह locale-sensitive परिवर्तन या Unicode case folding नहीं करता।

<a id="repeat"></a>

## दोहराओ (Repeat)

दिए गए पाठ की गिनती जितनी प्रतियाँ जोड़कर नया पाठ बनाता है। विभाजक अपने-आप नहीं लगता।

**हस्ताक्षर:**

- `पाठ्य.दोहराओ(मानक: पाठ, गिनती: पूर्णांक) → पाठ`

```bhash
लिखो(पाठ्य.दोहराओ("भा", ३));
लिखो("[" + पाठ्य.दोहराओ("क", ०) + "]");
```

**अपेक्षित आउटपुट:**

```text
भाभाभा
[]
```

गिनती ऋणात्मक नहीं हो सकती। परिणाम की सीमा १,०४८,५७६ UTF-16 code units है। खाली पाठ को दोहराने पर खाली पाठ ही मिलता है।

<a id="fixed-decimal-formatting-to-fixed"></a>

## संख्यापाठ (Fixed Decimal Formatting / To Fixed)

दशमलव संख्या का ASCII अंकों वाला पाठ बनाता है, जिसमें ठीक उतने ही दशमलव स्थान रहते हैं जितने माँगे गए हों। यह प्रदर्शन के लिए है; संख्या को exact decimal प्रकार में नहीं बदलता।

**हस्ताक्षर:**

- `पाठ्य.संख्यापाठ(मानक: दशमलव, स्थान: पूर्णांक) → पाठ`

```bhash
लिखो(पाठ्य.संख्यापाठ(१२.५, २));
लिखो(पाठ्य.संख्यापाठ(०.१२५, २));
लिखो(पाठ्य.संख्यापाठ(०.३७५, २));
लिखो(पाठ्य.संख्यापाठ(-०.०, २));
```

**अपेक्षित आउटपुट:**

```text
12.50
0.12
0.38
-0.00
```

स्थान ० से १५ तक हैं। वास्तविक binary64 मान को nearest, ties-to-even के अनुसार round किया जाता है। इसलिए ०.१२५ → 0.12 और ०.३७५ → 0.38 है। अन्य दशमलव literals binary64 में अनुमानित हो सकते हैं।

<a id="convert-digits-to-devanagari"></a>

## अंकदेवनागरी (Convert Digits to Devanagari)

पाठ में ASCII 0–9 को देवनागरी ०–९ में बदलता है। दशमलव बिंदु, ऋण चिह्न और अन्य अक्षर नहीं बदलते।

**हस्ताक्षर:**

- `पाठ्य.अंकदेवनागरी(मानक: पाठ) → पाठ`

```bhash
लिखो(पाठ्य.अंकदेवनागरी("Order 12: -3.50"));
```

**अपेक्षित आउटपुट:**

```text
Order १२: -३.५०
```

यह संख्या parse नहीं करता। हिन्दी में निश्चित दशमलव स्थान दिखाने के लिए संख्यापाठ के परिणाम पर इसे लगाएँ।

<a id="encode-utf-8"></a>

## यूटीएफ८ (Encode UTF-8)

पाठ को strict UTF-8 bytes के बाइटबफ़र में बदलता है। यह फ़ाइल या अन्य byte-आधारित डेटा के लिए encoding का चरण है।

**हस्ताक्षर:**

- `पाठ्य.यूटीएफ८(मानक: पाठ) → बाइटबफ़र`

```bhash
स्थिर बाइटें: बाइटबफ़र = पाठ्य.यूटीएफ८("A😀");
लिखो(बाइटें.आकार, बाइटें[०]);
```

**अपेक्षित आउटपुट:**

```text
५ ६५
```

A का एक byte और 😀 के चार bytes हैं। नया BOM नहीं जोड़ा जाता; अमान्य Unicode पर अपवाद आता है।

<a id="decode-utf-8"></a>

## यूटीएफ८पाठ (Decode UTF-8)

UTF-8 बाइटबफ़र को पाठ में बदलता है। अमान्य bytes को चुपचाप replacement character में नहीं बदलता।

**हस्ताक्षर:**

- `पाठ्य.यूटीएफ८पाठ(मानक: बाइटबफ़र) → पाठ`

```bhash
स्थिर बाइटें: बाइटबफ़र = पाठ्य.यूटीएफ८("नमस्ते😀");
लिखो(पाठ्य.यूटीएफ८पाठ(बाइटें));
```

**अपेक्षित आउटपुट:**

```text
नमस्ते😀
```

अमान्य UTF-8 पर अपवाद आता है। इनपुट में BOM पहले से मौजूद हो, तो वह पाठ में बना रहता है; encode और decode उसे अपने-आप हटाते नहीं हैं।
