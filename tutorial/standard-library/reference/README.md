# मानक पुस्तकालय की प्रकार सूची (Standard Library API)

भाष संकलक के `मानक` संकुल में 124 सार्वजनिक प्रकार हैं। हर नाम से उसके निर्माता, फलन, मापदंड, फल, क्षेत्र और कोड उदाहरण खोलें।

आम तौर पर `आयात मानक.प्रकार;` से नाम आयात करें। साझा फलन के लिए प्रकार का नाम, और सदस्य फलन के लिए बनी वस्तु का नाम उपयोग करें।

**रनटाइम** चिह्न वाले प्रकार संकलक या पुस्तकालय की अंदरूनी व्यवस्था के लिए हैं।

| [`सर्वरतंत्र` (Server Socket Bindings)](types/सर्वरतंत्र.md) | वर्ग · रनटाइम | सर्वर socket, पोर्ट और non-blocking बाइट क्रियाओं के निम्न-स्तरीय बंधन। |
| [`कूटशब्द` (Password Hashing)](types/कूटशब्द.md) | वर्ग | कूटशब्द का सुरक्षित हैश बनाएँ और बाद में कूटशब्द की पुष्टि करें। हैश संग्रहित करें। |
| [`सुरक्षा` (Security Utilities)](types/सुरक्षा.md) | वर्ग | गोपनीय टोकन बनाना और समय-आधारित जानकारी के रिसाव को सीमित करने वाली तुलना। |
| [`सुरक्षाघड़ी` (Security Clock)](types/सुरक्षाघड़ी.md) | वर्ग · रनटाइम | सत्र और प्रवेश दर की गणना के लिए वास्तविक समय। परीक्षण के लिए सत्रघड़ी का अपना कार्यान्वयन दें। |
| [`असमडाटातंत्र` (Async Database Bindings)](types/असमडाटातंत्र.md) | वर्ग · रनटाइम | पृष्ठभूमि डेटाबेस क्रियाओं के कच्चे हैंडल, परिणाम, निरस्तीकरण और सफ़ाई। |
