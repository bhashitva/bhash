# `वेब` (Web Response Utilities)

[सभी प्रकार](../README.md)

पाठ, HTML और JSON उत्तर बनाएँ, अनुरोध के मान पढ़ें और HTTP त्रुटि बनाएँ।

## सार्वजनिक फलन (Methods)

| फलन | बुलाने का रूप | मापदंड (नाम और प्रकार) | फल (प्रकार) | व्यवहार |
| --- | --- | --- | --- | --- |
| `मानलो` (Read Value) | साझा | `युग्म: सूची<पाठ>, नाम: पाठ` | `सूची<पाठ>` | दिए नाम या स्थिति से मान पढ़ता है। |
| `अंक` (Digit or Placeholder Index) | साझा | `मानक: पूर्णांक` | `पाठ` | एक अंक या मापदंड के सूचकांक का मान निकालता है। |
| `संख्या` (Parse Integer) | साझा | `मानक: पाठ, अधिकतम: पूर्णांक` | `पूर्णांक` | पाठ से पूर्णांक पढ़ता है। |
| `विकूटित` (Percent Decode) | साझा | `मानक: पाठ, जोड़: तार्किक` | `पाठ` | URL percent encoding से सामान्य पाठ बनाता है। |
| `पाठउत्तर` (Text Response) | साझा | `स्थिति: पूर्णांक, मानक: पाठ` | `वेबउत्तर` | दिए HTTP status के साथ UTF-8 पाठ उत्तर बनाता है। |
| `एचटीएमएल` (HTML Response) | साझा | `स्थिति: पूर्णांक, मानक: पाठ` | `वेबउत्तर` | दिए HTTP status के साथ HTML उत्तर बनाता है। |
| `जेसन` (JSON Response) | साझा | `स्थिति: पूर्णांक, मानक: सर्ववस्तु` | `वेबउत्तर` | दिए HTTP status के साथ JSON उत्तर बनाता है। |
| `त्रुटि` (HTTP Error Response) | साझा | `स्थिति: पूर्णांक` | `वेबउत्तर` | दिए HTTP स्थिति कोड के लिए सामान्य त्रुटि उत्तर बनाता है। |
| `आंतरिकमार्गखंड` (Split Route) | साझा, रनटाइम | `विधि: पाठ, पथ: पाठ` | `सूची<पाठ>` | राउटर के लिए मार्ग पैटर्न को खंडों में बाँटता है। |
| `आंतरिकमार्गमान` (Match Route) | साझा, रनटाइम | `खंड: सूची<पाठ>, मार्गखंड: सूची<पाठ>` | `मानचित्र<पाठ,पाठ>` | राउटर के लिए अनुरोध पथ से मार्ग के नामित मान निकालता है। |
