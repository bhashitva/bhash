# `संपीड़न` (Compression)

[सभी प्रकार](../README.md)

सीमित बाइटबफ़र को एक zlib 1.4 प्रदाता से जेडलिब या गज़िप में संपीड़ित और विसंपीड़ित करना।

**प्रकार** · वर्ग · `मानक.संपीड़न`

[व्यवहार, लक्ष्य और चलाने की तैयारी](../../../compression/README.md)

## निर्माता (Constructors)

यहाँ कोई सार्वजनिक निर्माता उपलब्ध नहीं है। साझा फलन या संबंधित फ़ैक्टरी से शुरू करें।

## सार्वजनिक फलन (Methods)

| फलन | बुलाने का रूप | मापदंड (नाम और प्रकार) | फल (प्रकार) | व्यवहार |
| --- | --- | --- | --- | --- |
| `संपीड़ितकरो` (Compress) | साझा | `मूल: बाइटबफ़र, प्रारूप: मानक.संपीड़नप्रारूप, स्तर: पूर्णांक` | `मानक.परिणाम<बाइटबफ़र,मानक.संपीड़नदोष>` | आगत बफ़र, जेडलिब/गज़िप प्रारूप और 0..9 स्तर से सफल बफ़र या संपीड़नदोष वाला परिणाम बनाता है। |
| `विसंपीड़ितकरो` (Decompress) | साझा | `मूल: बाइटबफ़र, प्रारूप: मानक.संपीड़नप्रारूप, अधिकतम: पूर्णांक` | `मानक.परिणाम<बाइटबफ़र,मानक.संपीड़नदोष>` | ठीक एक compressed stream को 1..16 MiB की दी सीमा में खोलकर सफल बफ़र या संपीड़नदोष लौटाता है। |

## उपयोग के उदाहरण (Usage examples)

ये कोड अंश हैं। आयात, आरंभिक मान और चलाने की तैयारी के लिए जुड़ा स्रोत या मार्गदर्शिका खोलें।

### उदाहरण 1

[संबंधित पूरा स्रोत या ट्यूटोरियल · roundtrip.bhash](../../../compression/roundtrip.bhash)

```bhash
मिलान (संपीड़न.संपीड़ितकरो(मूल, संपीड़नप्रारूप.गज़िप, ६)) {
    विकल्प मानक.परिणाम.असफल(स्थिर दोष): { लिखो(दोष.संदेश); }
    विकल्प मानक.परिणाम.सफल(स्थिर पैक): {
        मिलान (संपीड़न.विसंपीड़ितकरो(पैक, संपीड़नप्रारूप.गज़िप, १०२४)) {
            विकल्प मानक.परिणाम.असफल(स्थिर दोष): { लिखो(दोष.संदेश); }
            विकल्प मानक.परिणाम.सफल(स्थिर खुला): { लिखो(यूटीएफ८पाठ(खुला)); }
        }
    }
}
```

### उदाहरण 2

[संबंधित पूरा स्रोत या ट्यूटोरियल · errors.bhash](../../../compression/errors.bhash)

मिलान (संपीड़न.विसंपीड़ितकरो(मूल, संपीड़नप्रारूप.जेडलिब, १०२४)) {
    विकल्प मानक.परिणाम.सफल(स्थिर बफ़र): { लिखो("अप्रत्याशित सफलता"); }
