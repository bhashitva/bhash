# `डेटानियम` (SQLite Validation)

[सभी प्रकार](../README.md)

SQLite पाठ, पथ और कथन की इनपुट जाँच।

**प्रकार** · वर्ग · `मानक.डेटानियम`

**रनटाइम का सहायक प्रकार।** इसके सीधे उपयोग के लिए नीचे पुस्तकालय के कार्यान्वयन के अंश देखें।

| फलन | बुलाने का रूप | मापदंड (नाम और प्रकार) | फल (प्रकार) | व्यवहार |

| `पाठजाँचो` (Validate Database Text) | साझा | `मानक: पाठ, सीमा: पूर्णांक` | `शून्य` | डेटाबेस को दिया जाने वाला पाठ जाँचता है। |
