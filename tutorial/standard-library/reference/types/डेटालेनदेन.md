# `डेटालेनदेन` (Database Transaction)

[सभी प्रकार](../README.md)

साझा प्रदाता API में commit, rollback और scoped cleanup।

**प्रकार** · वर्ग · `मानक.डेटालेनदेन`

**आधार प्रकार और अनुबंध** · [`बंदनीय`](बंदनीय.md)

[व्यवहार, लक्ष्य और चलाने की तैयारी](../../../database-providers/README.md)

**उपयोग का अनुबंध** · सहेजो के सफल होने पर बदलाव स्थायी हैं। अधूरे लेनदेन को छोड़ने या बंद करने पर वापसी होती है।

## निर्माता (Constructors)

| निर्माण | मापदंड (नाम और प्रकार) | बना मान |
| --- | --- | --- |
| `नया डेटालेनदेन(मालिक, स्थानीय, पहचान, चिह्न)` | `मालिक: डेटासंबंध, स्थानीय: लेनदेन, पहचान: पूर्णांक, चिह्न: पूर्णांक` | `डेटालेनदेन` |

## सार्वजनिक फलन (Methods)

| फलन | बुलाने का रूप | मापदंड (नाम और प्रकार) | फल (प्रकार) | व्यवहार |
| --- | --- | --- | --- | --- |
| `सहेजो` (Commit Transaction) | सदस्य | — | `शून्य` | लेनदेन के बदलाव सहेजता है। |
| `वापसलो` (Roll Back) | सदस्य | — | `शून्य` | अभी सहेजे न गए लेनदेन बदलाव वापस लेता है। |
| `बंदकरो` (Close Transaction) | सदस्य | — | `शून्य` | सहेजे न गए प्रदाता लेनदेन को वापस लेकर बंद करता है। |

`शून्य` वाले फलन कोई मान नहीं लौटाते।

### उदाहरण 1

[संबंधित पूरा स्रोत या ट्यूटोरियल · README.md](../../../database-providers/README.md)

```bhash
संसाधन (ल: डेटालेनदेन = ड.लेनदेन()) {
    संसाधन (क: डेटाकथन = ड.तैयार("INSERT INTO tasks(id,title) VALUES (?,?)")) {
        क.पूर्णांकरखो(१,२); क.पाठरखो(२,"नया काम"); क.चलाओ();
    }
    ल.सहेजो();
}
```

### उदाहरण 2

[संबंधित पूरा स्रोत या ट्यूटोरियल · tasks.bhash](../../../../examples/typed-api/service/src/tasks.bhash)

```bhash
संसाधन (लेन: डेटालेनदेन = डाटा.लेनदेन()) {
    संसाधन (कथन: डेटाकथन = डाटा.तैयार("INSERT INTO typed_tasks(id,title,priority) VALUES (?,?,?) ON CONFLICT(id) DO NOTHING")) {
        कथन.पूर्णांकरखो(१,नया_कार्य.पहचान);
        कथन.पाठरखो(२,नया_कार्य.शीर्षक);
        कथन.पूर्णांकरखो(३,नया_कार्य.प्राथमिकता);
        यदि (कथन.चलाओ() == ०) { फेंको नया वेबत्रुटि(४०९,"पहचान पहले से है।"); }
    }
    लेन.सहेजो();
}
```
