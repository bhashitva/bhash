# `एसक्यूएलनियम` (SQL Provider Rules)

[सभी प्रकार](../README.md)

मापदंड क्रम और PostgreSQL placeholder अनुवाद के सहायक नियम।

**प्रकार** · वर्ग · `मानक.एसक्यूएलनियम`

**रनटाइम का सहायक प्रकार।** इसके सीधे उपयोग के लिए नीचे पुस्तकालय के कार्यान्वयन के अंश देखें।
