# `जेसन` (JSON)

[सभी प्रकार](../README.md)

JSON और भाष के सूची, मानचित्र, पाठ, संख्या तथा रिक्त मानों के बीच रूपांतरण।

**प्रकार** · वर्ग · `मानक.जेसन`

[व्यवहार, लक्ष्य और चलाने की तैयारी](../../README.md)

**उपयोग का अनुबंध** · JSON object से पाठ-कुंजी वाला मानचित्र और array से सूची मिलती है। JSON null का भाष मान रिक्त है। किसी पाठ को सीधे जोड़कर JSON बनाने की जगह पाठबनाओ उपयोग करें।

## निर्माता (Constructors)

यहाँ कोई सार्वजनिक निर्माता उपलब्ध नहीं है। साझा फलन या संबंधित फ़ैक्टरी से शुरू करें।

## सार्वजनिक फलन (Methods)

| फलन | बुलाने का रूप | मापदंड (नाम और प्रकार) | फल (प्रकार) | व्यवहार |
| --- | --- | --- | --- | --- |
| `पढ़ो` (Parse JSON) | साझा | `मानक: पाठ` | `सर्ववस्तु` | JSON पाठ से भाष का मान बनाता है। अमान्य JSON पर अपवाद आता है। |
| `पाठबनाओ` (Serialize JSON) | साझा | `मानक: सर्ववस्तु` | `पाठ` | भाष मान को JSON पाठ में बदलता है। चक्रीय संग्रह त्रुटि देते हैं। |
