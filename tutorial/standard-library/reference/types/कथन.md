| `बंधनसंख्या` (Parameter Count) | सदस्य | — | `पूर्णांक` | कथन में बाँधे जा सकने वाले मापदंडों की संख्या लौटाता है। |
| `पूर्णांकरखो` (Bind Integer) | सदस्य | `क्रम: पूर्णांक, मानक: पूर्णांक` | `शून्य` | क्रमांकित SQL मापदंड में पूर्णांक बाँधता है। |
| `दशमलवरखो` (Bind Decimal) | सदस्य | `क्रम: पूर्णांक, मानक: दशमलव` | `शून्य` | क्रमांकित SQL मापदंड में दशमलव बाँधता है। |
| `तार्किकरखो` (Bind Boolean) | सदस्य | `क्रम: पूर्णांक, मानक: तार्किक` | `शून्य` | क्रमांकित SQL मापदंड में तार्किक मान बाँधता है। |
| `पाठरखो` (Bind SQL Text) | सदस्य | `क्रम: पूर्णांक, मानक: पाठ` | `शून्य` | क्रमांकित SQL मापदंड में पाठ बाँधता है। |
| `बाइटरखो` (Bind Bytes) | सदस्य | `क्रम: पूर्णांक, मानक: बाइटबफ़र` | `शून्य` | क्रमांकित SQL मापदंड में बाइनरी सामग्री बाँधता है। |
| `रिक्तरखो` (Bind NULL) | सदस्य | `क्रम: पूर्णांक` | `शून्य` | क्रमांकित SQL मापदंड में SQL NULL बाँधता है। |
| `चलाओ` (Run) | सदस्य | — | `पूर्णांक` | क्रिया या कथन चलाता है। SQL के लिए फल प्रभावित पंक्तियों की गिनती है। |
| `अगला` (Read Next Row) | सदस्य | — | `तार्किक` | अगली SQL पंक्ति होने पर सत्य लौटाता है और उसे पढ़ने योग्य बनाता है। |
| `रीसेट` (Reset Statement) | सदस्य | — | `शून्य` | कथन का पढ़ने या चलने का स्थान फिर आरंभ पर लाता है। |
| `बंधनमिटाओ` (Clear Bindings) | सदस्य | — | `शून्य` | कथन के मापदंडों से सभी वर्तमान bindings हटाता है। |
| `स्तंभसंख्या` (Column Count) | सदस्य | — | `पूर्णांक` | वर्तमान SQL परिणाम में स्तंभों की संख्या लौटाता है। |
| `स्तंभनाम` (Column Name) | सदस्य | `क्रम: पूर्णांक` | `पाठ` | क्रमांकित परिणाम स्तंभ का नाम लौटाता है। |
| `प्रकार` (Column Type) | सदस्य | `क्रम: पूर्णांक` | `पाठ` | क्रमांकित स्तंभ का प्रकार लौटाता है। |
| `रिक्तहै` (Is NULL) | सदस्य | `क्रम: पूर्णांक` | `तार्किक` | जाँचता है कि वर्तमान स्तंभ का SQL मान NULL है। |
| `पूर्णांकलो` (Get Integer) | सदस्य | `क्रम: पूर्णांक` | `पूर्णांक` | वर्तमान पंक्ति के क्रमांकित स्तंभ को पूर्णांक के रूप में पढ़ता है। |
| `दशमलवलो` (Get Decimal) | सदस्य | `क्रम: पूर्णांक` | `दशमलव` | वर्तमान पंक्ति के क्रमांकित स्तंभ को दशमलव के रूप में पढ़ता है। |
| `तार्किकलो` (Get Boolean) | सदस्य | `क्रम: पूर्णांक` | `तार्किक` | वर्तमान पंक्ति के क्रमांकित स्तंभ को तार्किक मान में पढ़ता है। |
| `पाठलो` (Get Text) | सदस्य | `क्रम: पूर्णांक` | `पाठ` | वर्तमान पंक्ति के क्रमांकित स्तंभ को पाठ में पढ़ता है। |
| `बाइटलो` (Get Bytes) | सदस्य | `क्रम: पूर्णांक` | `बाइटबफ़र` | क्रमांकित स्तंभ या धारा से बाइट पढ़ता है। |
| `बंदकरो` (Close) | सदस्य | — | `शून्य` | संसाधन को बंद करके उससे जुड़े हैंडल या संदर्भ मुक्त करता है। |

`शून्य` वाले फलन कोई मान नहीं लौटाते।
