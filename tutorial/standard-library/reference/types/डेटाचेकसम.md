### उदाहरण 1

[रनटाइम का अंश · migrations.bhash](../../../../src/main/resources/dev/bhash/stdlib/migrations.bhash)

```bhash
जबतक (क < ६४) { स्थिर अ: पूर्णांक=व[क-१५]; स्थिर य: पूर्णांक=व[क-२]; स्थिर स०: पूर्णांक=डेटाचेकसम.घुमाओ(अ,७)^डेटाचेकसम.घुमाओ(अ,१८)^(अ >> ३); स्थिर स१: पूर्णांक=डेटाचेकसम.घुमाओ(य,१७)^डेटाचेकसम.घुमाओ(य,१९)^(य >> १०); व[क]=(व[क-१६]+स०+व[क-७]+स१)&४२९४९६७२९५; क=क+१; }
मान अ: पूर्णांक=ह[०]; मान आ: पूर्णांक=ह[१]; मान इ: पूर्णांक=ह[२]; मान ई: पूर्णांक=ह[३]; मान उ: पूर्णांक=ह[४]; मान ऊ: पूर्णांक=ह[५]; मान ए: पूर्णांक=ह[६]; मान ऐ: पूर्णांक=ह[७];
```
