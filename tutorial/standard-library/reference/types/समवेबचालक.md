# `समवेबचालक` (Sync Handler Adapter)

[सभी प्रकार](../README.md)

sync वेब चालक को async चालक के रूप में इस्तेमाल करने का आवरण।

**प्रकार** · वर्ग · `मानक.समवेबचालक`

**आधार प्रकार और अनुबंध** · [`असमवेबचालक`](असमवेबचालक.md)

[व्यवहार, लक्ष्य और चलाने की तैयारी](../../../../docs/async-http-server.md)

**उपयोग का अनुबंध** · अनुबंध असमकालिक कार्य देता है, लेकिन लिपटा हुआ sync चालक अपने काम के दौरान उसी तरह रुक सकता है जैसे सीधा sync कॉल।
