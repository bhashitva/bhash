# `असमजालप्रवेश` (Async HTTP Slot)

[सभी प्रकार](../README.md)

असमकालिक HTTP परिणाम प्राप्त करने और उसके परिवहन संसाधन साफ़ करने का सहायक।

**प्रकार** · वर्ग · `मानक.असमजालप्रवेश`

**रनटाइम का सहायक प्रकार।** इसके सीधे उपयोग के लिए नीचे पुस्तकालय के कार्यान्वयन के अंश देखें।
