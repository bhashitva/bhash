# `असमकालिकबंदनीय` (Async Closeable)

[सभी प्रकार](../README.md)

ऐसे संसाधन की सफ़ाई का अनुबंध जिसके बंदकरो फल पर प्रतीक्षा करनी है।

**प्रकार** · अनुबंध · `मानक.असमकालिकबंदनीय`

[व्यवहार, लक्ष्य और चलाने की तैयारी](../../../async/README.md)

**उपयोग का अनुबंध** · असमकालिक संसाधन कथन बंदकरो बुलाता है और सफ़ाई के कार्य पर प्रतीक्षा करता है। उदाहरण में साधन का असमकालिक फलन शून्य घोषित करता है।

## निर्माता (Constructors)

इस अनुबंध को किसी वर्ग में लागू करें।

## सार्वजनिक फलन (Methods)

| फलन | बुलाने का रूप | मापदंड (नाम और प्रकार) | फल (प्रकार) | व्यवहार |
| --- | --- | --- | --- | --- |
| `बंदकरो` (Close Resource Async) | सदस्य | — | `कार्यफल<कार्यशून्य>` | सफ़ाई शुरू करता है। लौटे कार्य पर प्रतीक्षा करके सफ़ाई का समापन जानें। |

## उपयोग के उदाहरण (Usage examples)

ये कोड अंश हैं। आयात, आरंभिक मान और चलाने की तैयारी के लिए जुड़ा स्रोत या मार्गदर्शिका खोलें।

### उदाहरण 1

[संबंधित पूरा स्रोत या ट्यूटोरियल · async-scope.bhash](../../reference-data/examples/async-scope.bhash)

```bhash
वर्ग साधन पालन असमकालिकबंदनीय {
    असमकालिक फलन बंदकरो() -> शून्य {
        प्रतीक्षा कार्य.छोड़ो();
        लिखो("साधन बंद");
    }
}
```

### उदाहरण 2

[संबंधित पूरा स्रोत या ट्यूटोरियल · async-scope.bhash](../../reference-data/examples/async-scope.bhash)

```bhash
असमकालिक संसाधन (स: असमकालिकबंदनीय = नया साधन()) {
    प्रतीक्षा कार्यसमूह.चलाओ(असमकालिक फलन() -> शून्य {
        स्थिर पहला: कार्यफल<शून्य> = कार्य.विलंब(१);
        स्थिर दूसरा: कार्यफल<शून्य> = कार्य.विलंब(२);
        प्रतीक्षा पहला;
        प्रतीक्षा दूसरा;
        लिखो("दोनों कार्य पूरे");
    });
}
```
