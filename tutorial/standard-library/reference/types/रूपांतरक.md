# `रूपांतरक<क, ख>` (Mapper)

[सभी प्रकार](../README.md)

एक प्रकार का मान लेकर दूसरे प्रकार का मान लौटाने का अनुबंध।

**प्रकार** · अनुबंध · `मानक.रूपांतरक<क, ख>`

[व्यवहार, लक्ष्य और चलाने की तैयारी](../../../application-foundations/README.md)

## निर्माता (Constructors)

इस अनुबंध को किसी वर्ग में लागू करें।

## सार्वजनिक फलन (Methods)

| फलन | बुलाने का रूप | मापदंड (नाम और प्रकार) | फल (प्रकार) | व्यवहार |
| --- | --- | --- | --- | --- |
| `बदलो` (Replace) | सदस्य | `मानक: क` | `ख` | दिए हुए पुराने पाठ की घटनाओं की जगह नया पाठ रखता है। |

## उपयोग के उदाहरण (Usage examples)

ये कोड अंश हैं। आयात, आरंभिक मान और चलाने की तैयारी के लिए जुड़ा स्रोत या मार्गदर्शिका खोलें।

### उदाहरण 1

[संबंधित पूरा स्रोत या ट्यूटोरियल · grouping.bhash](../../reference-data/examples/grouping.bhash)

```bhash
वर्ग समविषम पालन रूपांतरक<पूर्णांक, पाठ> {
    फलन बदलो(अंक: पूर्णांक) -> पाठ {
        यदि (अंक % २ == ०) { लौटाओ "सम"; }
        लौटाओ "विषम";
    }
}
```
