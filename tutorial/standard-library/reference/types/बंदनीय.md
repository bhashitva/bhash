# `बंदनीय` (Closeable)

[सभी प्रकार](../README.md)

ऐसा संसाधन जिसका बंदकरो संसाधन कथन स्वतः बुला सकता है।

**प्रकार** · अनुबंध · `मानक.बंदनीय`

[व्यवहार, लक्ष्य और चलाने की तैयारी](../../../application-foundations/README.md)

## निर्माता (Constructors)

इस अनुबंध को किसी वर्ग में लागू करें।

## सार्वजनिक फलन (Methods)

| फलन | बुलाने का रूप | मापदंड (नाम और प्रकार) | फल (प्रकार) | व्यवहार |
| --- | --- | --- | --- | --- |
| `बंदकरो` (Close Resource) | सदस्य | — | `शून्य` | संसाधन मुक्त करता है। कार्यान्वयन इसका ठोस व्यवहार तय करता है। |

`शून्य` वाले फलन कोई मान नहीं लौटाते।

## उपयोग के उदाहरण (Usage examples)

### उदाहरण 1

[संबंधित पूरा स्रोत या ट्यूटोरियल · resources.test.bhash](../../../../examples/foundations/resources.test.bhash)

```bhash
वर्ग गिनती पालन बंदनीय {
    सार्वजनिक मान बंद: पूर्णांक = ०;
    सार्वजनिक मान विफल: तार्किक = असत्य;
    सार्वजनिक फलन बंदकरो() -> शून्य { बंद = बंद + १; यदि (विफल) { फेंको नया अपवाद("सफाई त्रुटि"); } }
}
```

### उदाहरण 2

[रनटाइम का अंश · async-database.bhash](../../../../src/main/resources/dev/bhash/stdlib/async-database.bhash)

```bhash
सार्वजनिक वर्ग असमडेटाप्रवेश पालन बंदनीय {
    निजी मान संबंध:असमडेटासंबंध;

    सार्वजनिक फलन बंदकरो()->शून्य {यदि(संबंध!=रिक्त){संबंध.आंतरिकव्यस्त=असत्य;संबंध=रिक्त;}}
}
```
