# `प्रवाह` (File Stream)

[सभी प्रकार](../README.md)

एक ही खुले फ़ाइल हैंडल पर कई बार बाइट पढ़ें या लिखें। संसाधन कथन से बंद करें।

**प्रकार** · वर्ग · `मानक.प्रवाह`

**आधार प्रकार और अनुबंध** · [`बंदनीय`](बंदनीय.md)

[व्यवहार, लक्ष्य और चलाने की तैयारी](../../../application-foundations/README.md)

**उपयोग का अनुबंध** · पठन या लेखन से खुला प्रवाह लें और संसाधन कथन में रखें। पढ़ो में गिनती बाइटों की है। शून्य आकार का परिणाम धारा के अंत को दिखाता है। पाठलिखो UTF-8 बाइट लिखता है।

## निर्माता (Constructors)

यहाँ कोई सार्वजनिक निर्माता उपलब्ध नहीं है। साझा फलन या संबंधित फ़ैक्टरी से शुरू करें।

## सार्वजनिक फलन (Methods)

| फलन | बुलाने का रूप | मापदंड (नाम और प्रकार) | फल (प्रकार) | व्यवहार |
| --- | --- | --- | --- | --- |
| `पठन` (Open Read Stream) | साझा | `पथ: पाठ` | `प्रवाह` | पढ़ने के लिए खुला फ़ाइल प्रवाह लौटाता है। |
| `लेखन` (Open Write Stream) | साझा | `पथ: पाठ` | `प्रवाह` | लिखने के लिए खुला फ़ाइल प्रवाह लौटाता है। |
| `पढ़ो` (Read Stream Chunk) | सदस्य | `गिनती: पूर्णांक` | `बाइटबफ़र` | खुले प्रवाह से अधिकतम दी गई गिनती तक बाइट पढ़ता है। |
| `बाइटलिखो` (Write Bytes) | सदस्य | `सामग्री: बाइटबफ़र` | `शून्य` | दिए बाइट लिखता है। |
| `पाठलिखो` (Write Text) | सदस्य | `पाठ्यांश: पाठ` | `शून्य` | UTF-8 में पाठ लिखता है। |
| `भेजो` (Flush Stream) | सदस्य | — | `शून्य` | बफ़र किए लेखन को खुले प्रवाह में आगे भेजता है। |
| `बंदकरो` (Close Stream) | सदस्य | — | `शून्य` | खुले फ़ाइल हैंडल को बंद करता है। |

`शून्य` वाले फलन कोई मान नहीं लौटाते।

## उपयोग के उदाहरण (Usage examples)

ये कोड अंश हैं। आयात, आरंभिक मान और चलाने की तैयारी के लिए जुड़ा स्रोत या मार्गदर्शिका खोलें।

### उदाहरण 1

[संबंधित पूरा स्रोत या ट्यूटोरियल · README.md](../../../application-foundations/README.md)

```bhash
संसाधन (फ: प्रवाह = प्रवाह.लेखन("संदेश.txt")) {
    फ.पाठलिखो("नमस्ते, दुनिया!\n");
    फ.भेजो();
}
```

### उदाहरण 2

[संबंधित पूरा स्रोत या ट्यूटोरियल · README.md](../../../application-foundations/README.md)

```bhash
संसाधन (मूल: प्रवाह = प्रवाह.पठन("मूल.bin")) {
    संसाधन (फल: प्रवाह = प्रवाह.लेखन("प्रतिलिपि.bin")) {
        मान भाग: बाइटबफ़र = मूल.पढ़ो(८१९२);
        जबतक (भाग.आकार > ०) {
            फल.बाइटलिखो(भाग);
            भाग = मूल.पढ़ो(८१९२);
        }
    }
}
```
