# `वेबसंबंध` (HTTP Connection)

[सभी प्रकार](../README.md)

एक जुड़े HTTP socket पर अनुरोध और उत्तर के बाइट पढ़ें या लिखें।

**प्रकार** · वर्ग · `मानक.वेबसंबंध`

**आधार प्रकार और अनुबंध** · [`बंदनीय`](बंदनीय.md)

[व्यवहार, लक्ष्य और चलाने की तैयारी](../../../web-applications/README.md)

## सार्वजनिक फलन (Methods)

| फलन | बुलाने का रूप | मापदंड (नाम और प्रकार) | फल (प्रकार) | व्यवहार |
| --- | --- | --- | --- | --- |
| `आंतरिकखंडरखो` (Store Read Chunk) | सदस्य, रनटाइम | `मूल: बाइटबफ़र` | `शून्य` | पहले से पढ़े गए धारा खंड को संबंध में रखता है। |
| `बंदकरो` (Close) | सदस्य | — | `शून्य` | संसाधन को बंद करके उससे जुड़े हैंडल या संदर्भ मुक्त करता है। |
| `बाइटलो` (Get Bytes) | सदस्य | — | `पूर्णांक` | क्रमांकित स्तंभ या धारा से बाइट पढ़ता है। |
| `पंक्तिलो` (Read Protocol Line) | सदस्य | — | `पाठ` | संबंध से एक HTTP पंक्ति पढ़ता है। |
| `आंतरिकशीर्षलो` (Read Request Head) | सदस्य, रनटाइम | — | `वेबशीर्षभाग` | HTTP अनुरोध-पंक्ति और headers पढ़ता है। |
| `अनुरोधलो` (Read Request) | सदस्य | — | `वेबअनुरोध` | धारा या socket से पूरा वेब अनुरोध पढ़ता है। |
| `उत्तरशीर्ष` (Encode Response Headers) | सदस्य | `उत्तर: वेबउत्तर` | `पाठ` | HTTP उत्तर का शीर्ष भाग बाइट में तैयार करता है। |
| `उत्तरदो` (Write Response) | सदस्य | `उत्तर: वेबउत्तर, केवलशीर्ष: तार्किक` | `शून्य` | संबंध पर HTTP उत्तर लिखता है। |

`शून्य` वाले फलन कोई मान नहीं लौटाते।
