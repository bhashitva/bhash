# `वेबसॉकेटसंदर्भ` (WebSocket Context)

[सभी प्रकार](../README.md)

उन्नत संबंध के पथ मापदंड, उपप्रोटोकॉल और सत्र की अनुमति जाँचें।

**प्रकार** · वर्ग · `मानक.वेबसॉकेटसंदर्भ`

[व्यवहार, लक्ष्य और चलाने की तैयारी](../../../../docs/websocket.md)

| --- | --- | --- |
| `नया वेबसॉकेटसंदर्भ(प्रबंधक, प्रवेश, पथमान, उपप्रोटोकॉल)` | `प्रबंधक: सत्रप्रबंधक, प्रवेश: सत्र, पथमान: मानचित्र<पाठ,पाठ>, उपप्रोटोकॉल: पाठ` | `वेबसॉकेटसंदर्भ` |

## सार्वजनिक फलन (Methods)

| फलन | बुलाने का रूप | मापदंड (नाम और प्रकार) | फल (प्रकार) | व्यवहार |
| --- | --- | --- | --- | --- |
| `जीवितहै` (Is Session Alive) | सदस्य | — | `तार्किक` | जाँचता है कि WebSocket संदर्भ का सत्र जीवित है। |
| `अधिकृत` (Require Authorization) | सदस्य | — | `सत्र` | सत्र या संदर्भ में आवश्यक अनुमति जाँचता है। |

## सार्वजनिक क्षेत्र (Fields)

| क्षेत्र | प्रकार | रूप | पहुँच | अर्थ |
| --- | --- | --- | --- | --- |
| `पथमान` | `मानचित्र<पाठ,पाठ>` | सदस्य | पढ़ना और लिखना | राउटर से मिले नामित पथ खंडों के मान। |
| `उपप्रोटोकॉल` | `पाठ` | सदस्य | पढ़ना और लिखना | संबंध के लिए चुना गया WebSocket उपप्रोटोकॉल। |

## उपयोग के उदाहरण (Usage examples)

ये कोड अंश हैं। आयात, आरंभिक मान और चलाने की तैयारी के लिए जुड़ा स्रोत या मार्गदर्शिका खोलें।

### उदाहरण 1

[संबंधित पूरा स्रोत या ट्यूटोरियल · server.bhash](../../../../examples/websocket/server.bhash)

```bhash
सार्वजनिक असमकालिक फलन संभालो(संदर्भ: वेबसॉकेटसंदर्भ, संबंध: वेबसॉकेटसंबंध, चिह्न: निरस्तीकरणचिह्न) -> शून्य {
    संदर्भ.अधिकृत();
    जबतक (सत्य) {
        स्थिर संदेश: वेबसॉकेटसंदेश = प्रतीक्षा संबंध.पाओ(चिह्न);
        यदि (संदेश.प्रकार=="बंद") { लौटाओ; }
        यदि (संदेश.प्रकार=="पाठ") { प्रतीक्षा संबंध.पाठभेजो(संदेश.पाठ्यांश,चिह्न); }
        अन्यथा { प्रतीक्षा संबंध.बाइटभेजो(संदेश.बाइटें,चिह्न); }
    }
}
```

### उदाहरण 2

[संबंधित पूरा स्रोत या ट्यूटोरियल · stream.bhash](../../../../examples/websocket/stream.bhash)

```bhash
सार्वजनिक असमकालिक फलन संभालो(संदर्भ: वेबसॉकेटसंदर्भ, संबंध: वेबसॉकेटसंबंध, चिह्न: निरस्तीकरणचिह्न) -> शून्य {
    स्थिर संदेश: वेबसॉकेटसंदेश=प्रतीक्षा संबंध.पाओ(चिह्न);
    यदि (संदेश.प्रकार!="पाठ" || संदेश.पाठ्यांश!="hi") { फेंको नया अपवाद("अमान्य संदेश।"); }
    प्रतीक्षा संबंध.पाठभेजो(संदेश.पाठ्यांश,चिह्न);
    प्रतीक्षा संबंध.बंदकरो();
    समाप्त=सत्य;
}
```
