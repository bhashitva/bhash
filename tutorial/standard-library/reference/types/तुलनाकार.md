# `तुलनाकार<त>` (Comparator)

[सभी प्रकार](../README.md)

दो मानों की तुलना करने का अनुबंध। ऋणात्मक, शून्य या धनात्मक फल क्रम बताता है।

**प्रकार** · अनुबंध · `मानक.तुलनाकार<त>`

[व्यवहार, लक्ष्य और चलाने की तैयारी](../../../application-foundations/README.md)

## निर्माता (Constructors)

## सार्वजनिक फलन (Methods)

| फलन | बुलाने का रूप | मापदंड (नाम और प्रकार) | फल (प्रकार) | व्यवहार |
| --- | --- | --- | --- | --- |

### उदाहरण 1

[संबंधित पूरा स्रोत या ट्यूटोरियल · collections.test.bhash](../../../../examples/foundations/collections.test.bhash)

```bhash
वर्ग पंक्तिक्रम पालन मानक.तुलनाकार<पंक्ति> {
    सार्वजनिक फलन तुलना(क: पंक्ति, ख: पंक्ति) -> पूर्णांक {
        यदि (क.कुंजी < ख.कुंजी) { लौटाओ -१; } यदि (क.कुंजी > ख.कुंजी) { लौटाओ १; } लौटाओ ०;
    }
}
```
