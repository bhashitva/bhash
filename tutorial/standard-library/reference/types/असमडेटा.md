## उपयोग के उदाहरण (Usage examples)

ये कोड अंश हैं। आयात, आरंभिक मान और चलाने की तैयारी के लिए जुड़ा स्रोत या मार्गदर्शिका खोलें।

### उदाहरण 1

[संबंधित पूरा स्रोत या ट्यूटोरियल · sqlite.bhash](../../../async-io/sqlite.bhash)

```bhash
असमकालिक संसाधन(ड:असमडेटासंबंध=प्रतीक्षा असमडेटा.एसक्यूलाइट(":memory:")){
    असमकालिक संसाधन(क:असमडेटाकथन=प्रतीक्षा ड.तैयार("CREATE TABLE notes(id INTEGER PRIMARY KEY,title TEXT NOT NULL)")){
        स्थिर बदले:पूर्णांक=प्रतीक्षा क.चलाओ();
    }
    प्रतीक्षा सहेजो(ड);
    असमकालिक संसाधन(क:असमडेटाकथन=प्रतीक्षा ड.तैयार("SELECT title FROM notes ORDER BY id")){
        जबतक(प्रतीक्षा क.अगला()){लिखो(क.पाठलो(०));}
    }
}
```

### उदाहरण 2

[संबंधित पूरा स्रोत या ट्यूटोरियल · sqlserver.md](../../../database-providers/sqlserver.md)

```bhash
असमकालिक संसाधन (ड: असमडेटासंबंध = प्रतीक्षा असमडेटा.एसक्यूएलसर्वर(संबंधपाठ)) {
    स्थिर छात्र: विद्यार्थीसंग्रह = नया विद्यार्थीसंग्रह(ड);
    स्थिर मिला: विद्यार्थी = प्रतीक्षा छात्र.पहचानसेपाओ(१०);
    यदि (मिला != रिक्त) {
        स्थिर कक्षा: कक्षास्तर = प्रतीक्षा छात्र.कक्षास्तरलो(मिला);
        यदि (कक्षा != रिक्त) { लिखो(मिला.नाम, कक्षा.नाम); }
    }
}
```
