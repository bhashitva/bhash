# `असमडेटा` (Async Database Providers)

### उदाहरण 1

[संबंधित पूरा स्रोत या ट्यूटोरियल · sqlite.bhash](../../../async-io/sqlite.bhash)

```bhash
असमकालिक संसाधन(ड:असमडेटासंबंध=प्रतीक्षा असमडेटा.एसक्यूलाइट(":memory:")){
    असमकालिक संसाधन(क:असमडेटाकथन=प्रतीक्षा ड.तैयार("CREATE TABLE notes(id INTEGER PRIMARY KEY,title TEXT NOT NULL)")){
        स्थिर बदले:पूर्णांक=प्रतीक्षा क.चलाओ();
    }
    प्रतीक्षा सहेजो(ड);
    असमकालिक संसाधन(क:असमडेटाकथन=प्रतीक्षा ड.तैयार("SELECT title FROM notes ORDER BY id")){
        जबतक(प्रतीक्षा क.अगला()){लिखो(क.पाठलो(०));}
    }
}
```
