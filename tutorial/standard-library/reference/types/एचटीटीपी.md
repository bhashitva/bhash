# `एचटीटीपी` (HTTP Client)

[सभी प्रकार](../README.md)

सिंक्रोनस और असमकालिक HTTP या HTTPS अनुरोध भेजें।

**प्रकार** · वर्ग · `मानक.एचटीटीपी`

[व्यवहार, लक्ष्य और चलाने की तैयारी](../../../networking/README.md)

**उपयोग का अनुबंध** · सिंक्रोनस विधियाँ उत्तर आने तक रुकती हैं। असमकालिक विधियाँ कार्यफल देती हैं और निरस्तीकरण चिह्न स्वीकारने वाले ओवरलोड भी हैं। HTTP त्रुटि status को उत्तर से अलग पढ़ें।

## सार्वजनिक फलन (Methods)

| फलन | बुलाने का रूप | मापदंड (नाम और प्रकार) | फल (प्रकार) | व्यवहार |
| --- | --- | --- | --- | --- |
| `कूटित` (Percent Encode) | साझा | `मानक: पाठ` | `पाठ` | पाठ को URL घटक में रखने के लिए percent-encode करता है। |
| `पाओ` (HTTP GET) | साझा | `पता: पाठ` | `एचटीटीपीउत्तर` | URL पर सिंक्रोनस GET भेजता है और HTTP उत्तर देता है। |
| `पाओअसमकालिक` (Get Async) | साझा | `पता: पाठ` | `कार्यफल<एचटीटीपीउत्तर>` | HTTP GET शुरू करता है और प्रतीक्षा योग्य उत्तर देता है। |
| `पाओअसमकालिक` (Get Async) | साझा | `पता: पाठ, चिह्न: निरस्तीकरणचिह्न` | `कार्यफल<एचटीटीपीउत्तर>` | HTTP GET शुरू करता है और प्रतीक्षा योग्य उत्तर देता है। |
| `भेजोअसमकालिक` (Send Async) | साझा | `अनुरोध: एचटीटीपीअनुरोध` | `कार्यफल<एचटीटीपीउत्तर>` | HTTP अनुरोध शुरू करता है और प्रतीक्षा योग्य उत्तर देता है। |
| `भेजोअसमकालिक` (Send Async) | साझा | `अनुरोध: एचटीटीपीअनुरोध, चिह्न: निरस्तीकरणचिह्न` | `कार्यफल<एचटीटीपीउत्तर>` | HTTP अनुरोध शुरू करता है और प्रतीक्षा योग्य उत्तर देता है। |
| `भेजो` (Send HTTP Request) | साझा | `अनुरोध: एचटीटीपीअनुरोध` | `एचटीटीपीउत्तर` | दिए अनुरोध को सिंक्रोनस भेजता है और HTTP उत्तर देता है। |
