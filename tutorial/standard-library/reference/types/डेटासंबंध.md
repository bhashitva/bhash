# `डेटासंबंध` (Database Connection)

[सभी प्रकार](../README.md)

प्रदाता का नाम जानें, SQL कथन तैयार करें, लेनदेन शुरू करें और संसाधन बंद करें।

**प्रकार** · वर्ग · `मानक.डेटासंबंध`

**आधार प्रकार और अनुबंध** · [`बंदनीय`](बंदनीय.md)

[व्यवहार, लक्ष्य और चलाने की तैयारी](../../../database-providers/README.md)

**उपयोग का अनुबंध** · संसाधन कथन का उपयोग करें। तैयार के SQL में डेटा मानों के लिए ? लिखें और मापदंड बाँधें। SQL में उपयोगकर्ता का पाठ जोड़ने से बचें।

## निर्माता (Constructors)

| निर्माण | मापदंड (नाम और प्रकार) | बना मान |
| --- | --- | --- |
| `नया डेटासंबंध(पथ, विन्यास)` | `पथ: पाठ, विन्यास: पोस्टग्रेसविन्यास` | `डेटासंबंध` |

## सार्वजनिक फलन (Methods)

| फलन | बुलाने का रूप | मापदंड (नाम और प्रकार) | फल (प्रकार) | व्यवहार |
| --- | --- | --- | --- | --- |
| `प्रदाता` (Provider Name) | सदस्य | — | `पाठ` | संबंध में उपयोग हो रहे प्रदाता का नाम लौटाता है। |
| `जाँचो` (Check Connection) | सदस्य | — | `शून्य` | जाँचता है कि इस संबंध पर अभी क्रिया की जा सकती है। |
| `तैयार` (Prepare Statement) | सदस्य | `एसक्यूएल: पाठ` | `डेटाकथन` | मापदंडयुक्त SQL से पुनः उपयोग योग्य कथन तैयार करता है। |
| `लेनदेन` (Begin Transaction) | सदस्य | — | `डेटालेनदेन` | संबंध पर लेनदेन आरंभ करता है। |
| `बंदकरो` (Close) | सदस्य | — | `शून्य` | संसाधन को बंद करके उससे जुड़े हैंडल या संदर्भ मुक्त करता है। |

`शून्य` वाले फलन कोई मान नहीं लौटाते।

### उदाहरण 1

[संबंधित पूरा स्रोत या ट्यूटोरियल · migrations.bhash](../../../database-providers/migrations.bhash)

```bhash
संसाधन (ड: डेटासंबंध = डेटा.एसक्यूलाइट("tasks.db")) {
    लिखो("लागू बदलाव: ",योजना.लागूकरो(ड));
    योजना.जाँचो(ड);
    प्रत्येक (योजना.स्थिति(ड) में म: माइग्रेशनस्थिति) { लिखो(म.संस्करण," ",म.नाम," ",म.लागू); }
    संसाधन (क: डेटाकथन = ड.तैयार("INSERT INTO tasks(id,title) VALUES (?,?) ON CONFLICT(id) DO NOTHING")) {
        क.पूर्णांकरखो(१,१); क.पाठरखो(२,"भारत😀 का स्वागत"); क.चलाओ();
    }
    संसाधन (क: डेटाकथन = ड.तैयार("SELECT title FROM tasks ORDER BY id")) { जबतक (क.अगला()) { लिखो(क.पाठलो(०)); } }
}
```
