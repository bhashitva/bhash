# `वेबचालक` (Web Handler)

[सभी प्रकार](../README.md)

एक sync वेब अनुरोध को वेब उत्तर में बदलने का अनुबंध।

**प्रकार** · अनुबंध · `मानक.वेबचालक`

[व्यवहार, लक्ष्य और चलाने की तैयारी](../../../web-applications/README.md)

## निर्माता (Constructors)

इस अनुबंध को किसी वर्ग में लागू करें।

## सार्वजनिक फलन (Methods)

| फलन | बुलाने का रूप | मापदंड (नाम और प्रकार) | फल (प्रकार) | व्यवहार |
| --- | --- | --- | --- | --- |
| `संभालो` (Handle) | सदस्य | `अनुरोध: वेबअनुरोध` | `वेबउत्तर` | अनुरोध या संबंध को चालक के नियम से सँभालता है। |

### उदाहरण 1

[संबंधित पूरा स्रोत या ट्यूटोरियल · 03-authorization.bhash](../../../authentication/examples/03-authorization.bhash)

```bhash
वर्ग खाता पालन वेबचालक {
    सार्वजनिक फलन संभालो(अ: वेबअनुरोध) -> वेबउत्तर { लौटाओ वेब.पाठउत्तर(२००,"अनुमति मिली।"); }
}
```
