# `वेबशीर्षभाग` (Parsed HTTP Head)

[सभी प्रकार](../README.md)

पढ़ी हुई अनुरोध-पंक्ति, HTTP शीर्ष और शरीर की लंबाई रखता है।

**प्रकार** · वर्ग · `मानक.वेबशीर्षभाग`

**रनटाइम का सहायक प्रकार।** इसके सीधे उपयोग के लिए नीचे पुस्तकालय के कार्यान्वयन के अंश देखें।

[व्यवहार, लक्ष्य और चलाने की तैयारी](../../../web-applications/README.md)

| फलन | बुलाने का रूप | मापदंड (नाम और प्रकार) | फल (प्रकार) | व्यवहार |

## सार्वजनिक क्षेत्र (Fields)

| क्षेत्र | प्रकार | रूप | पहुँच | अर्थ |
| --- | --- | --- | --- | --- |
| `विधि` | `पाठ` | सदस्य | पढ़ना और लिखना | HTTP विधि, जैसे GET या POST। |
| `लक्ष्य` | `पाठ` | सदस्य | पढ़ना और लिखना | HTTP अनुरोध का पथ और वैकल्पिक query। |
| `शीर्ष` | `सूची<पाठ>` | सदस्य | पढ़ना और लिखना | क्रम से रखे header नाम और मान के युग्म। |
| `आकार` | `पूर्णांक` | सदस्य | पढ़ना और लिखना | HTTP शीर्ष से निकली शरीर की बाइट लंबाई। |
| `संस्करण` | `पाठ` | सदस्य | पढ़ना और लिखना | HTTP अनुरोध-पंक्ति से पढ़ा गया protocol version। |
