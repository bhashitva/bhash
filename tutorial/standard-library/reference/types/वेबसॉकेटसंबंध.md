# `वेबसॉकेटसंबंध` (WebSocket Connection)

[सभी प्रकार](../README.md)

संदेश पाएँ या भेजें, निरस्तीकरण दें और बंद होने का handshake चलाएँ।

**प्रकार** · वर्ग · `मानक.वेबसॉकेटसंबंध`

[व्यवहार, लक्ष्य और चलाने की तैयारी](../../../../docs/websocket.md)

**उपयोग का अनुबंध** · संदेश पाने, भेजने और बंद करने वाले कार्यों पर प्रतीक्षा करें। पाठ संदेश और बाइनरी संदेश का भेद रखें। प्रत्येक संदेश के लिए नया HTTP अनुरोध नहीं बनता।

## निर्माता (Constructors)

| निर्माण | मापदंड (नाम और प्रकार) | बना मान |
| --- | --- | --- |
| `नया वेबसॉकेटसंबंध(धारा)` | `धारा: द्विदिशधारा` | `वेबसॉकेटसंबंध` |

## सार्वजनिक फलन (Methods)

| फलन | बुलाने का रूप | मापदंड (नाम और प्रकार) | फल (प्रकार) | व्यवहार |
| --- | --- | --- | --- | --- |
| `पाओ` (Receive WebSocket Message) | सदस्य | — | `कार्यफल<वेबसॉकेटसंदेश>` | अगला पूरा text, binary या close संदेश प्राप्त करने का कार्य देता है। |
| `पाओ` (Receive WebSocket Message) | सदस्य, असमकालिक | `चिह्न: निरस्तीकरणचिह्न` | `वेबसॉकेटसंदेश` · प्रतीक्षा का फल | अगला पूरा text, binary या close संदेश प्राप्त करने का कार्य देता है। |
| `पाठभेजो` (Send Text Message) | सदस्य | `मानक: पाठ` | `कार्यफल<कार्यशून्य>` | WebSocket पर पाठ संदेश भेजता है। |
| `पाठभेजो` (Send Text Message) | सदस्य | `मानक: पाठ, चिह्न: निरस्तीकरणचिह्न` | `कार्यफल<कार्यशून्य>` | WebSocket पर पाठ संदेश भेजता है। |
| `बाइटभेजो` (Send Binary Message) | सदस्य | `मानक: बाइटबफ़र` | `कार्यफल<कार्यशून्य>` | WebSocket पर बाइनरी संदेश भेजता है। |
| `बाइटभेजो` (Send Binary Message) | सदस्य | `मानक: बाइटबफ़र, चिह्न: निरस्तीकरणचिह्न` | `कार्यफल<कार्यशून्य>` | WebSocket पर बाइनरी संदेश भेजता है। |
| `आंतरिकप्रेषणछोड़ो` (Release Send Slot) | सदस्य, रनटाइम | — | `शून्य` | अगले WebSocket प्रेषण के लिए आंतरिक जगह खाली करता है। |
| `बंदकरो` (Close WebSocket) | सदस्य | — | `कार्यफल<कार्यशून्य>` | दिए code और कारण से WebSocket बंद होने का handshake शुरू करता है। |
| `बंदकरो` (Close WebSocket) | सदस्य, असमकालिक | `कोड: पूर्णांक, कारण: पाठ` | `शून्य` · प्रतीक्षा का फल | दिए code और कारण से WebSocket बंद होने का handshake शुरू करता है। |
| `चलाओ` (Run WebSocket Session) | सदस्य, असमकालिक | `संदर्भ: वेबसॉकेटसंदर्भ, चालक: वेबसॉकेटचालक, रोक: निरस्तीकरणचिह्न` | `शून्य` · प्रतीक्षा का फल | संबंध और संदर्भ देकर संदेश चालक चलाता है। |

`शून्य` वाले फलन कोई मान नहीं लौटाते।

## उपयोग के उदाहरण (Usage examples)

ये कोड अंश हैं। आयात, आरंभिक मान और चलाने की तैयारी के लिए जुड़ा स्रोत या मार्गदर्शिका खोलें।

### उदाहरण 1

[संबंधित पूरा स्रोत या ट्यूटोरियल · server.bhash](../../../../examples/websocket/server.bhash)

```bhash
सार्वजनिक असमकालिक फलन संभालो(संदर्भ: वेबसॉकेटसंदर्भ, संबंध: वेबसॉकेटसंबंध, चिह्न: निरस्तीकरणचिह्न) -> शून्य {
    संदर्भ.अधिकृत();
    जबतक (सत्य) {
        स्थिर संदेश: वेबसॉकेटसंदेश = प्रतीक्षा संबंध.पाओ(चिह्न);
        यदि (संदेश.प्रकार=="बंद") { लौटाओ; }
        यदि (संदेश.प्रकार=="पाठ") { प्रतीक्षा संबंध.पाठभेजो(संदेश.पाठ्यांश,चिह्न); }
        अन्यथा { प्रतीक्षा संबंध.बाइटभेजो(संदेश.बाइटें,चिह्न); }
    }
}
```
