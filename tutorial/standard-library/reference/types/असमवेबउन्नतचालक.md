# `असमवेबउन्नतचालक` (Upgraded Protocol Handler)

[सभी प्रकार](../README.md)

उन्नयन का HTTP उत्तर दें और फिर उसी द्विदिश धारा पर नया protocol चलाएँ।

**प्रकार** · अनुबंध · `मानक.असमवेबउन्नतचालक`

**आधार प्रकार और अनुबंध** · [`बंदनीय`](बंदनीय.md)

[व्यवहार, लक्ष्य और चलाने की तैयारी](../../../../docs/async-http-server.md)

## निर्माता (Constructors)

इस अनुबंध को किसी वर्ग में लागू करें।

## सार्वजनिक फलन (Methods)

| फलन | बुलाने का रूप | मापदंड (नाम और प्रकार) | फल (प्रकार) | व्यवहार |
| --- | --- | --- | --- | --- |
| `उत्तरलो` (Get Upgrade Response) | सदस्य | — | `बाइटबफ़र` | उन्नयन से पहले भेजा जाने वाला HTTP उत्तर देता है। |
| `चलाओ` (Run Upgraded Protocol) | सदस्य | `धारा: द्विदिशधारा, रोक: निरस्तीकरणचिह्न` | `कार्यफल<कार्यशून्य>` | हाथ मिलाने के बाद उसी धारा पर protocol का कार्य चलाता है। |
| `बंदकरो` (Close Resource) | सदस्य | — | `शून्य` | [`बंदनीय`](बंदनीय.md) · संसाधन मुक्त करता है। कार्यान्वयन इसका ठोस व्यवहार तय करता है। |

`शून्य` वाले फलन कोई मान नहीं लौटाते।

## उपयोग के उदाहरण (Usage examples)

ये कोड अंश हैं। आयात, आरंभिक मान और चलाने की तैयारी के लिए जुड़ा स्रोत या मार्गदर्शिका खोलें।

### उदाहरण 1

[संबंधित पूरा स्रोत या ट्यूटोरियल · stream.bhash](../../../../examples/websocket/stream.bhash)

```bhash
संसाधन (चयनित: असमवेबउन्नतचालक=मार्ग.चुनो(अनुरोध)) {
    स्थिर उत्तर: पाठ=पाठ्य.यूटीएफ८पाठ(चयनित.उत्तरलो());
    यदि (!पाठ्य.आरंभ(उत्तर,"HTTP/1.1 101 ") ||
        !पाठ्य.है(उत्तर,"Sec-WebSocket-Accept: s3pPLMBiTxaQ9kYGzzhZRbK+xOo=\r\n") ||
        !पाठ्य.है(उत्तर,"Sec-WebSocket-Protocol: bhash.echo\r\n")) {
        फेंको नया अपवाद("WebSocket उत्तर असंगत।");
    }
}
```

### उदाहरण 2

[रनटाइम का अंश · websocket.bhash](../../../../src/main/resources/dev/bhash/stdlib/websocket.bhash)

```bhash
सार्वजनिक वर्ग वेबसॉकेटउन्नयन पालन असमवेबउन्नतचालक {
    निजी मान मार्ग: वेबसॉकेटमार्ग;
    निजी मान चालक: वेबसॉकेटचालक;
    निजी मान संदर्भ: वेबसॉकेटसंदर्भ;
    निजी मान उत्तर: बाइटबफ़र;
    सार्वजनिक निर्माता(मार्ग: वेबसॉकेटमार्ग, चालक: वेबसॉकेटचालक, संदर्भ: वेबसॉकेटसंदर्भ, उत्तर: बाइटबफ़र) {
        यह.मार्ग=मार्ग; यह.चालक=चालक; यह.संदर्भ=संदर्भ; यह.उत्तर=उत्तर;
    }
    सार्वजनिक फलन उत्तरलो() -> बाइटबफ़र { लौटाओ उत्तर; }
    सार्वजनिक फलन चलाओ(धारा: द्विदिशधारा, रोक: निरस्तीकरणचिह्न) -> कार्यफल<कार्यशून्य> {
        स्थिर संबंध: वेबसॉकेटसंबंध=नया वेबसॉकेटसंबंध(धारा);
        लौटाओ संबंध.चलाओ(संदर्भ,चालक,रोक);
    }
    सार्वजनिक फलन बंदकरो() -> शून्य { यदि (मार्ग!=रिक्त) { मार्ग.आंतरिकछोड़ो(); मार्ग=रिक्त; } }
}
```
