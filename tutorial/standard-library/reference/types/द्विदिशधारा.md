# `द्विदिशधारा` (Bidirectional Stream)

[सभी प्रकार](../README.md)

आने वाले और जाने वाले बाइट की async धारा। उपयोग के बाद बंद करें।

**प्रकार** · अनुबंध · `मानक.द्विदिशधारा`

**आधार प्रकार और अनुबंध** · [`बंदनीय`](बंदनीय.md)

[व्यवहार, लक्ष्य और चलाने की तैयारी](../../../../docs/async-http-server.md)

**उपयोग का अनुबंध** · पढ़ो का रिक्त परिणाम अभी बाइट उपलब्ध न होने का संकेत है। शून्य आकार का बफ़र EOF है। भेजो आंशिक प्रेषण की संख्या दे सकता है।

## निर्माता (Constructors)

इस अनुबंध को किसी वर्ग में लागू करें।

## सार्वजनिक फलन (Methods)

| फलन | बुलाने का रूप | मापदंड (नाम और प्रकार) | फल (प्रकार) | व्यवहार |
| --- | --- | --- | --- | --- |
| `पढ़ो` (Read Available Bytes) | सदस्य | — | `बाइटबफ़र` | बिना रुके उपलब्ध बाइट लौटाता है। रिक्त का अर्थ अभी प्रगति नहीं है, और खाली बफ़र धारा का अंत है। |
| `भेजो` (Write Available Bytes) | सदस्य | `खंड: बाइटबफ़र` | `पूर्णांक` | बिना रुके लिखे गए बाइटों की संख्या लौटाता है। शेष बाइट बाद में भेजें। |
| `बंदकरो` (Close Resource) | सदस्य | — | `शून्य` | [`बंदनीय`](बंदनीय.md) · संसाधन मुक्त करता है। कार्यान्वयन इसका ठोस व्यवहार तय करता है। |

`शून्य` वाले फलन कोई मान नहीं लौटाते।

## उपयोग के उदाहरण (Usage examples)

ये कोड अंश हैं। आयात, आरंभिक मान और चलाने की तैयारी के लिए जुड़ा स्रोत या मार्गदर्शिका खोलें।

### उदाहरण 1

[संबंधित पूरा स्रोत या ट्यूटोरियल · stream.bhash](../../../../examples/websocket/stream.bhash)

```bhash
वर्ग रुकीधारा पालन द्विदिशधारा {
    सार्वजनिक मान लिखे: पूर्णांक=०;
    सार्वजनिक मान प्रयासगिनती: पूर्णांक=०;
    सार्वजनिक मान बंदगिनती: पूर्णांक=०;
    निजी मान क्षमता: पूर्णांक;
    निर्माता(क्षमता: पूर्णांक) { यह.क्षमता=क्षमता; }
    सार्वजनिक फलन पढ़ो() -> बाइटबफ़र { लौटाओ रिक्त; }
    सार्वजनिक फलन भेजो(खंड: बाइटबफ़र) -> पूर्णांक {
        प्रयासगिनती=प्रयासगिनती+१;
        यदि (लिखे>=क्षमता) { लौटाओ ०; }
        लिखे=लिखे+१; लौटाओ १;
    }
    सार्वजनिक फलन बंदकरो() -> शून्य { बंदगिनती=बंदगिनती+१; }
}
```

### उदाहरण 2

[रनटाइम का अंश · async-web.bhash](../../../../src/main/resources/dev/bhash/stdlib/async-web.bhash)

```bhash
सार्वजनिक वर्ग असमसॉकेटधारा पालन द्विदिशधारा {
    निजी मान संबंध: वेबसंबंध;
    निजी मान बचाखंड: बाइटबफ़र;
    सार्वजनिक निर्माता(संबंध: वेबसंबंध, बचाखंड: बाइटबफ़र) { यह.संबंध = संबंध; यह.बचाखंड = बचाखंड; }
    सार्वजनिक फलन पढ़ो() -> बाइटबफ़र {
        यदि (बचाखंड != रिक्त) { स्थिर फल: बाइटबफ़र = बचाखंड; बचाखंड = रिक्त; लौटाओ फल; }
        लौटाओ सर्वरतंत्र.तुरंतपढ़ो(संबंध.पहचान);
    }
    सार्वजनिक फलन भेजो(खंड: बाइटबफ़र) -> पूर्णांक { लौटाओ सर्वरतंत्र.तुरंतलिखो(संबंध.पहचान,खंड); }
    सार्वजनिक फलन बंदकरो() -> शून्य { बचाखंड = रिक्त; संबंध.बंदकरो(); }
}
```
