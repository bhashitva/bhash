# रनटाइम में प्रकारों का उपयोग (Runtime usage)

नीचे के अंश पुस्तकालय या संकलक की अंदरूनी व्यवस्था समझाते हैं। इनमें
हैंडल, समयसीमा और संसाधन का स्वामित्व उसी व्यवस्था से मिलता है। अनुप्रयोग
लिखते समय जुड़ी उच्च-स्तरीय API और उसके पूरे उदाहरण से शुरू करें।

## HTTP परिवहन

सिंक्रोनस परिवहन किसी उत्तर को उसके हैंडल से पढ़ता है और उसे साफ़ करता है।
[पूरा परिवहन कार्यान्वयन](../../../src/main/resources/dev/bhash/stdlib/networking.bhash) देखें।

```bhash
संसाधन (उत्तर: जालउत्तरप्रवाह = नया जालउत्तरप्रवाह()) {
    उत्तर.पहचान = जालतंत्र.भेजो(विधि, पता, शीर्ष, शरीर, समयसीमा);
    लिखो(जालतंत्र.स्थिति(उत्तर.पहचान));
}
```

असमकालिक परिवहन में लंबे समय तक रहने वाले काम को उसकी पहचान से संभाला जाता है।

```bhash
फलन वर्तमान(धारा: असमजालप्रवाह) -> पूर्णांक {
    लौटाओ धारा.पहचान;
}
```

रद्द करने का चिह्न और समाप्ति का समय लेकर async क्लाइंट का भीतरी काम शुरू होता है।

```bhash
स्थिर परिणाम: एचटीटीपीउत्तर = प्रतीक्षा असमजाल.चलाओ(अनुरोध, चिह्न, समाप्ति);
लिखो(परिणाम.स्थिति());
```

## कार्य अनुसूचक

[कार्य अनुसूचक का स्रोत](../../../src/main/resources/dev/bhash/stdlib/tasks.bhash)
और [असमकालिक कार्य ट्यूटोरियल](../../async/README.md) देखें।

अनुसूचक निरस्तीकरण चिह्न को ध्यान में रखने वाला प्रतीक्षा आवरण आरंभ करता है।

```bhash
स्थिर प्रतीक्षी: प्रतीक्षाकार्य<पूर्णांक> = नया प्रतीक्षाकार्य<पूर्णांक>(गणना, रोक);
कार्यतंत्र.आरम्भ(प्रतीक्षी);
```

असमकालिक संसाधन में प्रवेश पर संकलक नई संरचित सीमा बनाता है।

```bhash
स्थिर सीमा: कार्यसीमा = नया कार्यसीमा();
कार्यतंत्र.सीमाआरम्भ(सीमा);
वर्तमान.आंतरिकसीमा = सीमा;
```

सीमा बंद करते समय संकलक पहले आश्रित काम का परिणाम देखता है।

```bhash
फलन पूर्णताजाँच(सीमा: कार्यसीमा) -> शून्य {
    सीमा.आंतरिकपरिणामजाँचो();
}
```

समूह callback को स्वतंत्र कार्य के रूप में कतार में रखकर उसका परिणाम देखा जाता है।

```bhash
स्थिर समूह: समूहकार्य = नया समूहकार्य(काम);
कार्यतंत्र.आरम्भ(समूह);
प्रतीक्षा समूह;
```

विलंब के लिए अनुसूचक अपेक्षित समय और निरस्तीकरण साथ रखता है।

```bhash
स्थिर सोता: विलंबकार्य = नया विलंबकार्य(१०, रोक);
कार्यतंत्र.आरम्भ(सोता);
प्रतीक्षा सोता;
```

## डेटाबेस का पृष्ठभूमि परिणाम

[असमकालिक डेटाबेस कार्यान्वयन](../../../src/main/resources/dev/bhash/stdlib/async-database.bhash)
कच्चे क्रिया हैंडल से प्रतीक्षा योग्य पूर्णांक परिणाम बनाता है।

```bhash
स्थिर पूरा: असमडेटाप्रतीक्षा = नया असमडेटाप्रतीक्षा(पहचान, चिह्न, प्रतिबद्ध, पहलेनिरस्त);
कार्यतंत्र.आरम्भ(पूरा);
स्थिर गिनती: पूर्णांक = प्रतीक्षा पूरा;
```

## HTTP upgrade और WebSocket

[HTTP upgrade का स्रोत](../../../src/main/resources/dev/bhash/stdlib/async-web.bhash)
में स्वीकृत संबंध और उसके बचे बाइट नई धारा में जाते हैं।

```bhash
संसाधन (धारा: असमसॉकेटधारा = नया असमसॉकेटधारा(खुला, आगमन.बचाखंड)) {
    स्थिर उपलब्ध: बाइटबफ़र = धारा.पढ़ो();
    यदि (उपलब्ध != रिक्त) { लिखो(उपलब्ध.आकार); }
}
```

WebSocket की प्रेषण जगह को सीमित संसाधन की तरह बंद किया जाता है।
[सत्र का स्रोत](../../../src/main/resources/dev/bhash/stdlib/websocket.bhash)
में यह जगह सफल प्रेषण अनुमति के बाद बनाई जाती है।

```bhash
फलन जगहछोड़ो(प्रवेश: वेबसॉकेटप्रेषणप्रवेश) -> शून्य {
    प्रवेश.बंदकरो();
}
```

उन्नयन का उत्तर और उसके बाद के सत्र का कार्य अलग-अलग उपलब्ध हैं।

```bhash
असमकालिक फलन सत्रचलाओ(उन्नयन: वेबसॉकेटउन्नयन, धारा: द्विदिशधारा, रोक: निरस्तीकरणचिह्न) -> शून्य {
    // HTTP उन्नयन के सभी उत्तर बाइट पहले भेजे जा चुके हैं।
    प्रतीक्षा उन्नयन.चलाओ(धारा, रोक);
}
```
