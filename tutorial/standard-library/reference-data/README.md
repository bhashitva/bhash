# प्रकार संदर्भ का रखरखाव (Maintaining the API reference)

[सभी प्रकारों की प्रकाशित स्रोत सूची](../reference/README.md) और उसके पृष्ठ
संकलक के वास्तविक निर्यात से बनते हैं। संस्करण बदलने पर जनित पृष्ठ सीधे
संपादित करने की जगह नीचे की सामग्री बदलें।

- `types.txt` में सार्वजनिक प्रकार का अंग्रेज़ी नाम और हिन्दी परिचय दें।
  संकलक या पुस्तकालय के आंतरिक प्रकारों के लिए अंतिम कॉलम में `internal` लिखें।
- `methods.txt` में हिन्दी व्यवहार और परिचित अंग्रेज़ी नाम लिखें। अलग व्यवहार के
  लिए `प्रकार.फलन` की प्रविष्टि सामान्य नाम की प्रविष्टि पर प्राथमिकता लेती है।
  मापदंडों, फल प्रकारों और ओवरलोड की सूची संकलक से आती है।
- `fields.txt` में सार्वजनिक क्षेत्र का अर्थ लिखें। `प्रकार.क्षेत्र` से किसी एक प्रकार के लिए अर्थ बदल सकते हैं।
- `notes.txt` में लक्ष्य, इकाई, अपवाद, सीमा और संसाधन स्वामित्व जैसे अनुबंध लिखें।
- `examples.txt` से किसी प्रकार के लिए खास स्रोत को प्राथमिकता दें।
  किसी निश्चित अंश के लिए `फ़ाइल::पंक्ति का अंश` लिखें।
  चलने योग्य छोटे उदाहरण `examples/` में अपेक्षित आउटपुट के साथ रखें।
  `runtime-uses.md` में आंतरिक API के संदर्भ अंश हैं।

```sh
mvn --batch-mode --no-transfer-progress -DskipTests package
python scripts/build_library_reference.py
python scripts/build_library_reference.py --check --test-examples jvm
python scripts/build_library_reference.py --check --test-examples clr
```

नया हस्ताक्षर, प्रकार या दो उदाहरणों से कम वाली प्रविष्टि आने पर जाँच रुकती
है। उदाहरण चुनने के बाद उनके अंश और जुड़े स्रोत की समीक्षा करें।
