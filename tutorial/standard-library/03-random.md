# यादृच्छिक अनुक्रम (Pseudorandom Numbers)

यह पूरा module experimental native Linux x86-64 target पर भी उपलब्ध है। [Native व्यवहार, errors और cross-target जाँच](../../docs/native-math-random.md) देखें।

ये फ़ंक्शन SplitMix64 छद्म-यादृच्छिक अनुक्रम पर आधारित हैं। खेल और simulation के लिए उपयोगी हैं; पासवर्ड, सुरक्षा token या cryptography के लिए नहीं। बीज पूरे चल रहे कार्यक्रम की library अवस्था बदलता है। एक ही बीज और एक ही क्रम में किए गए calls JVM, CLR और browser पर एक ही अनुक्रम देते हैं।

[मानक पुस्तकालय का सूचकांक](README.md) · [पूरा चलाने योग्य उदाहरण](examples/03-random.bhash) · [पूरे उदाहरण का अपेक्षित आउटपुट](examples/03-random.expected.txt)

नीचे हर छोटा कोड-खंड अलग उदाहरण है। उसे इस ढाँचे में मुख्य() के भीतर रखें; एक साथ सभी उदाहरण चलाने के लिए ऊपर दी गई पूरी फ़ाइल प्रयोग करें।

```bhash
आयात मानक.यादृच्छिक;
कार्य मुख्य() -> शून्य {
    // नीचे दिए गए किसी एक उदाहरण का कोड यहाँ रखें।
}
```

<a id="seed"></a>

## बीज (Seed)

छद्म-यादृच्छिक जनरेटर की आरंभिक अवस्था तय करता है। कोई मान वापस नहीं देता। परीक्षण में परिणाम दोहराने के लिए यही बीज फिर से दें।

**हस्ताक्षर:**

- `यादृच्छिक.बीज(मानक: पूर्णांक) → शून्य`

```bhash
यादृच्छिक.बीज(४२);
स्थिर पहला: पूर्णांक = यादृच्छिक.पूर्णांकचुनो(१, ७);
यादृच्छिक.बीज(४२);
लिखो(पहला == यादृच्छिक.पूर्णांकचुनो(१, ७));
```

**अपेक्षित आउटपुट:**

```text
सत्य
```

बीज signed 64-bit पूर्णांक है; ऋणात्मक बीज भी मान्य है। बीज के बिना default अवस्था पर किसी निश्चित आउटपुट का भरोसा न करें।

<a id="random-integer-next-int"></a>

## पूर्णांकचुनो (Random Integer / Next Int)

निम्न सीमा सहित और ऊपरी सीमा के पहले तक समान संभावना से पूर्णांक चुनता है। पासे के लिए १ और ७ दें; ७ कभी नहीं मिलेगा।

**हस्ताक्षर:**

- `यादृच्छिक.पूर्णांकचुनो(निम्न: पूर्णांक, ऊपरी: पूर्णांक) → पूर्णांक`

```bhash
यादृच्छिक.बीज(०);
लिखो(यादृच्छिक.पूर्णांकचुनो(०, १००), यादृच्छिक.पूर्णांकचुनो(०, १००), यादृच्छिक.पूर्णांकचुनो(०, १००));
```

**अपेक्षित आउटपुट:**

```text
६७ ५० ३९
```

निम्न < ऊपरी होना चाहिए और उनका अंतर signed 64-bit की धनात्मक सीमा में होना चाहिए। बराबर या उलटी सीमाएँ अपवाद देती हैं। इस उदाहरण में बीज फिर से लगाया गया है, इसलिए यह पहले उदाहरण से स्वतंत्र है।

<a id="random-fraction-next-double"></a>

## अंश (Random Fraction / Next Double)

०.० सहित और १.० के पहले तक दशमलव लौटाता है। १.० परिणाम में शामिल नहीं है। पाठ्य.अंश से इसका अर्थ अलग है, इसलिए module नाम सहित call पढ़ें।

**हस्ताक्षर:**

- `यादृच्छिक.अंश() → दशमलव`

```bhash
यादृच्छिक.बीज(७);
स्थिर संख्या: दशमलव = यादृच्छिक.अंश();
लिखो(संख्या >= ०.० && संख्या < १.०);
यादृच्छिक.बीज(७);
लिखो(संख्या == यादृच्छिक.अंश());
```

**अपेक्षित आउटपुट:**

```text
सत्य
सत्य
```

मान अपने-आप प्रदर्शित नहीं होता। यहाँ निश्चित दशमलव पाठ की बजाय सीमा और दोहराव की जाँच दिखाई गई है। इसे call करना भी अनुक्रम की अवस्था आगे बढ़ाता है।
