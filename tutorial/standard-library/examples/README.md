# चलाने योग्य उदाहरण (Runnable Examples)

इस फ़ोल्डर में छह library modules और त्रुटियों के सात पूरे कार्यक्रम हैं। हर .bhash फ़ाइल के साथ उसी नाम की .expected.txt फ़ाइल उसका JVM/CLR आउटपुट दिखाती है। उदाहरण अपने module और function का नाम आउटपुट में छापते हैं ताकि संबंधित भाग आसानी से मिल सके।

चलाने के तरीके, फ़ाइल उदाहरण की तैयारी और सत्यापन आदेश [मुख्य संदर्भ](../README.md) में हैं। छोटे narrative programs की जाँच भी verify.mjs में शामिल है।
