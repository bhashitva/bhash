# समय और दिनांक (UTC Date and Time)

सभी समय मान Unix epoch, यानी 1970-01-01T00:00:00.000Z, से milliseconds की signed 64-bit गिनती हैं। सभी calendar operations Gregorian UTC में हैं; स्थानीय timezone या daylight saving conversion यहाँ नहीं है। निश्चित उदाहरणों में 2000 का leap day लिया गया है।

[मानक पुस्तकालय का सूचकांक](README.md) · [पूरा चलाने योग्य उदाहरण](examples/05-time.bhash) · [पूरे उदाहरण का अपेक्षित आउटपुट](examples/05-time.expected.txt)

नीचे हर छोटा कोड-खंड अलग उदाहरण है। उसे इस ढाँचे में मुख्य() के भीतर रखें; एक साथ सभी उदाहरण चलाने के लिए ऊपर दी गई पूरी फ़ाइल प्रयोग करें।

```bhash
आयात मानक.समय;
कार्य मुख्य() -> शून्य {
    // नीचे दिए गए किसी एक उदाहरण का कोड यहाँ रखें।
}
```

<a id="current-time-now"></a>

## अभी (Current Time / Now)

host की घड़ी से वर्तमान epoch milliseconds लौटाता है। हर call का मान बदल सकता है। इसे stopwatch के लिए monotonic clock न समझें; system clock बदली जा सकती है।

**हस्ताक्षर:**

- `समय.अभी() → पूर्णांक`

```bhash
स्थिर क्षण: पूर्णांक = समय.अभी();
लिखो(क्षण > ०);
```

**अपेक्षित आउटपुट:**

```text
सत्य
```

वर्तमान युग में यह epoch के बाद होने की जाँच है, कोई स्थिर timestamp नहीं। वास्तविक UTC पाठ देखने के लिए लिखो(समय.पाठबनाओ(क्षण)); करें; उसका परिणाम चलाने के समय पर निर्भर होगा।

<a id="parse-utc-timestamp"></a>

## पढ़ो (Parse UTC Timestamp)

ठीक yyyy-MM-ddTHH:mm:ss.SSSZ प्रारूप का ASCII दिनांक-पाठ epoch milliseconds में बदलता है। महीना और दिन calendar के अनुसार वैध होने चाहिए।

**हस्ताक्षर:**

- `समय.पढ़ो(मानक: पाठ) → पूर्णांक`

```bhash
लिखो(समय.पढ़ो("1970-01-01T00:00:00.000Z"));
स्थिर क्षण: पूर्णांक = समय.पढ़ो("2000-02-29T12:34:56.789Z");
लिखो(समय.पाठबनाओ(क्षण));
```

**अपेक्षित आउटपुट:**

```text
०
2000-02-29T12:34:56.789Z
```

अंत में Z और ठीक तीन fractional digits आवश्यक हैं। offset जैसे +05:30, छोड़े गए milliseconds, leap seconds और 1900-02-29 जैसे अमान्य दिनांक अस्वीकार होते हैं। मान्य वर्ष 0001 से 9999 हैं।

<a id="format-utc-timestamp"></a>

## पाठबनाओ (Format UTC Timestamp)

epoch milliseconds को उसी निश्चित UTC प्रारूप में बदलता है। परिणाम के अंक ASCII हैं और milliseconds के तीन स्थान हमेशा रहते हैं।

**हस्ताक्षर:**

- `समय.पाठबनाओ(मानक: पूर्णांक) → पाठ`

```bhash
लिखो(समय.पाठबनाओ(०));
लिखो(समय.पाठबनाओ(-१));
```

**अपेक्षित आउटपुट:**

```text
1970-01-01T00:00:00.000Z
1969-12-31T23:59:59.999Z
```

मान्य timestamp सीमा -६२१३५५९६८००००० से २५३४०२३००७९९९९९ milliseconds तक है। इसके बाहर फ़ंक्शन अपवाद देता है।

<a id="year"></a>

## वर्ष (Year)

दिए गए timestamp का UTC calendar वर्ष लौटाता है। यह epoch से बीते वर्षों की गिनती नहीं है।

**हस्ताक्षर:**

- `समय.वर्ष(मानक: पूर्णांक) → पूर्णांक`

```bhash
स्थिर क्षण: पूर्णांक = समय.पढ़ो("2000-02-29T12:34:56.789Z");
लिखो(समय.वर्ष(क्षण));
```

**अपेक्षित आउटपुट:**

```text
२०००
```

दिनांक की वही मान्य सीमा लागू होती है। स्थानीय timezone में वर्ष सीमा अलग लग सकती है, लेकिन यह फ़ंक्शन UTC का वर्ष ही देता है।

<a id="month"></a>

## माह (Month)

दिए गए timestamp का UTC महीना १ से १२ तक लौटाता है। जनवरी १ है, ० नहीं।

**हस्ताक्षर:**

- `समय.माह(मानक: पूर्णांक) → पूर्णांक`

```bhash
स्थिर क्षण: पूर्णांक = समय.पढ़ो("2000-02-29T12:34:56.789Z");
लिखो(समय.माह(क्षण));
```

**अपेक्षित आउटपुट:**

```text
२
```

JavaScript Date.getMonth जैसे शून्य-आधारित API से तुलना करते समय यह अंतर ध्यान रखें।

<a id="day-of-month"></a>

## दिन (Day of Month)

दिए गए timestamp के UTC महीने का दिन लौटाता है। यह सप्ताह का दिन या वर्ष का क्रमांक नहीं है।

**हस्ताक्षर:**

- `समय.दिन(मानक: पूर्णांक) → पूर्णांक`

```bhash
स्थिर क्षण: पूर्णांक = समय.पढ़ो("2000-02-29T12:34:56.789Z");
लिखो(समय.दिन(क्षण));
```

**अपेक्षित आउटपुट:**

```text
२९
```

महीने और leap year के अनुसार दिन १ से २८, २९, ३० या ३१ तक हो सकता है।
