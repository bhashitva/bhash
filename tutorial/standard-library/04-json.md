# जेसन डेटा पढ़ना और बनाना (JSON Parsing and Serialization)

JSON एक डेटा प्रारूप है, executable code नहीं। जेसन.पढ़ो का परिणाम सर्ववस्तु होता है; उपयोग करने से पहले उसके वास्तविक प्रकार की जाँच या स्पष्ट cast करें। JSON पाठ के भीतर अंक ASCII में होने चाहिए, भले ही भाष के source code में देवनागरी अंक लिखे गए हों।

[मानक पुस्तकालय का सूचकांक](README.md) · [पूरा चलाने योग्य उदाहरण](examples/04-json.bhash) · [पूरे उदाहरण का अपेक्षित आउटपुट](examples/04-json.expected.txt)

नीचे हर छोटा कोड-खंड अलग उदाहरण है। उसे इस ढाँचे में मुख्य() के भीतर रखें; एक साथ सभी उदाहरण चलाने के लिए ऊपर दी गई पूरी फ़ाइल प्रयोग करें।

```bhash
आयात मानक.जेसन;
कार्य मुख्य() -> शून्य {
    // नीचे दिए गए किसी एक उदाहरण का कोड यहाँ रखें।
}
```

<a id="parse-json"></a>

## पढ़ो (Parse JSON)

वैध JSON पाठ को भाष के मानों में बदलता है। object मानचित्र<पाठ,सर्ववस्तु>, array सूची<सर्ववस्तु>, string पाठ, integer lexeme पूर्णांक, fraction/exponent दशमलव, boolean तार्किक और null रिक्त बनते हैं।

**हस्ताक्षर:**

- `जेसन.पढ़ो(मानक: पाठ) → सर्ववस्तु`

```bhash
स्थिर मूल: सर्ववस्तु = जेसन.पढ़ो("{\"नाम\":\"सीमा\",\"अंक\":[21,22]}");
स्थिर छात्र: मानचित्र<पाठ,सर्ववस्तु> = परिवर्तित<मानचित्र<पाठ,सर्ववस्तु>>(मूल);
स्थिर अंक: सूची<सर्ववस्तु> = परिवर्तित<सूची<सर्ववस्तु>>(छात्र["अंक"]);
लिखो(परिवर्तित<पाठ>(छात्र["नाम"]), अंक.आकार, परिवर्तित<पूर्णांक>(अंक[०]));
स्थिर प्रकार: सूची<सर्ववस्तु> = परिवर्तित<सूची<सर्ववस्तु>>(जेसन.पढ़ो("[1,1.0,true,null]"));
लिखो(प्रकारहै<पूर्णांक>(प्रकार[०]), प्रकारहै<दशमलव>(प्रकार[१]), प्रकारहै<तार्किक>(प्रकार[२]), प्रकार[३] == रिक्त);
```

**अपेक्षित आउटपुट:**

```text
सीमा २ २१
सत्य सत्य सत्य सत्य
```

१ और १.० source literals की जगह JSON string के भीतर 1 और 1.0 हैं। गलत JSON, duplicate keys, trailing comma, अतिरिक्त tokens, non-ASCII अंक, अमान्य Unicode, सीमा से बाहर integer और non-finite संख्या अस्वीकार होती है। signed 64-bit integer सटीक रहता है। इनपुट सीमा १,०४८,५७६ UTF-16 code units और recursive depth सीमा ६४ है। गलत cast भी अपवाद दे सकता है; बाहरी डेटा का प्रकार पहले जाँचें।

<a id="stringify-json-serialize"></a>

## पाठबनाओ (Stringify JSON / Serialize)

समर्थित भाष मान को JSON पाठ में बदलता है। यह strings को quotes/escaping के साथ, booleans को true/false, और पूर्णांक को सटीक ASCII अंकों में लिखता है।

**हस्ताक्षर:**

- `जेसन.पाठबनाओ(मानक: सर्ववस्तु) → पाठ`

```bhash
स्थिर वस्तु: मानचित्र<पाठ,सर्ववस्तु> = नया मानचित्र<पाठ,सर्ववस्तु>{"नाम":"सीमा", "अंक":नया सूची<पूर्णांक>{१,२}};
लिखो(जेसन.पाठबनाओ(वस्तु));
लिखो(जेसन.पाठबनाओ(नया सूची<सर्ववस्तु>{सत्य, असत्य, रिक्त}));
लिखो(जेसन.पाठबनाओ(९२२३३७२०३६८५४७७५८०७));
लिखो(प्रकारहै<दशमलव>(जेसन.पढ़ो(जेसन.पाठबनाओ(१.०))));
```

**अपेक्षित आउटपुट:**

```text
{"नाम":"सीमा","अंक":[1,2]}
[true,false,null]
9223372036854775807
सत्य
```

सरणी, सूची, बाइटबफ़र और पाठ-कुंजी वाले मानचित्र समर्थित हैं। मानचित्र की insertion order रहती है; class instances, records और enums को पहले समर्थित मानों में बदलें। चक्रीय संग्रह अपवाद देता है, जबकि एक ही child को दो जगह रखना मान्य है। आउटपुट सीमा १,०४८,५७६ UTF-16 code units और depth सीमा ६४ है। दशमलव की spelling अलग targets पर अलग हो सकती है; canonical byte format न मानें। बाहरी JavaScript Number बड़े integers की सटीकता खो सकता है, भले ही भाष ने उन्हें सटीक लिखा हो।
