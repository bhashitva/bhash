# ५. पुस्तकालय और सुरक्षित संसाधन (Libraries and resources)

[← पिछला अध्याय](04-modeling.md) · [विषय सूची](README.md) · [अगला अध्याय →](06-projects-and-testing.md)

कार्य का शीर्षक कभी खाली जगहों के साथ आता है। बाहर की सेवा को काम
भेजते समय JSON चाहिए। कुछ काम फ़ाइल से पढ़े जाते हैं। इन तीनों के लिए
भाष के मानक पुस्तकालय में तैयार साधन हैं। `आयात मानक.पाठ्य;` से पाठ
वाली विधियाँ छोटी लिख सकते हैं। फ़ाइल की शुरुआत में आयात रखें।

जब आपको किसी वर्ग या अन्य सार्वजनिक प्रकार की सही विधि ढूँढनी हो,
[हिन्दी API संदर्भ](../tutorial/standard-library/reference/README.md) में उसका पृष्ठ खोलें।
वहाँ उसके निर्माता, मापदंड, लौटाए गए मान और उपयोग के उदाहरण मिलेंगे।

| काम | पढ़ें और चलाएँ |
| --- | --- |
| पाठ काटना, ढूँढना, बाँटना, जोड़ना और अंक दिखाना | [पाठ्य (Text)](../tutorial/standard-library/01-text.md) |
| गणित, दशमलव परिणाम और बीज से दोहराए जाने वाले यादृच्छिक मान | [गणित (Math)](../tutorial/standard-library/02-math.md), [यादृच्छिक (Random)](../tutorial/standard-library/03-random.md) |
| JSON पढ़ना और लिखना | [जेसन (JSON)](../tutorial/standard-library/04-json.md) |
| तारीख और समय | [समय (Time)](../tutorial/standard-library/05-time.md) |
| UTF-8 पाठ, बाइटबफ़र और स्थानीय फ़ाइल | [फ़ाइल (Files)](../tutorial/standard-library/06-files.md), [बाइनरी उदाहरण](../examples/native/bytes.bhash) |
| प्रवाह, पथ, निर्देशिका और संग्रह के सामान्य कलन | [अनुप्रयोग का आधार (Application foundations)](../tutorial/application-foundations/README.md) |

जब API से JSON आए, पहले उसका आकार और प्रकार जाँचें। JSON वस्तु के लिए
`मानचित्र<पाठ,सर्ववस्तु>` तथा JSON सरणी के लिए `सूची<सर्ववस्तु>`
मिलती है। पाठ को सीधे जोड़कर JSON बनाने से उद्धरण या नई पंक्ति वाले
शीर्षक पर त्रुटि हो सकती है। मानचित्र या सूची बनाकर
`जेसन.पाठबनाओ` को दें। [JSON उदाहरण](../tutorial/standard-library/examples/04-json.bhash)
में एक शीर्षक को `भारत😀` से बदलें और फिर पढ़कर मिलाएँ।

## विफलता और सफ़ाई (Exceptions and resource scopes)

ग़लत JSON, अनुपलब्ध फ़ाइल और अमान्य रूपांतरण सामान्य विफलताएँ हैं।
`प्रयास` में जोखिम वाला काम रखें। जिस अपवाद से उबर सकते हैं, उसे
`पकड़ो` में सँभालें। अपना अपवाद `फेंको` से भेज सकते हैं।
`अंततः` वह काम रखता है जिसे ब्लॉक छोड़ते समय करना है। अपवाद और लौटने
दोनों मार्ग [अपवाद उदाहरण](../examples/exceptions.bhash) और
[नियम](../docs/exceptions.md) से समझें।

प्रवाह, डेटाबेस संबंध और कथन में बाहरी संसाधन भी होते हैं।
`संसाधन` ब्लॉक से निकलने पर उसका `बंदकरो()` बुलाता है। इस तरह
सफलता, जल्दी लौटने और अपवाद के रास्तों पर एक ही सफ़ाई लागू होती है।
[संसाधन परीक्षण](../examples/foundations/resources.test.bhash) में इन
रास्तों को देखें। मेमोरी की सफ़ाई अपने आप होती है, लेकिन बाहरी हैंडल
समय पर बंद करने के लिए संसाधन का दायरा लिखें।

**खुद आज़माएँ।** [फ़ाइल अभ्यास](../tutorial/standard-library/examples/06-files.bhash)
एक अलग अभ्यास फ़ोल्डर में चलाएँ। सही फ़ाइल के साथ एक अनुपलब्ध पथ भी
आज़माएँ। Playground में JSON वाला अभ्यास चुनें। स्थानीय फ़ाइल वाले काम
desktop JVM, CLR या native पर करें।
