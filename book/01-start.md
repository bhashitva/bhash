# १. अपना पहला क्रमानुदेश (Getting started)

[विषय सूची](README.md) · [अगला अध्याय →](02-values-and-flow.md)

मान लीजिए आप घर या कक्षा के कामों की सूची बना रहे हैं। सबसे पहले कंप्यूटर
से एक पंक्ति लिखवाएँ। इससे पता चलता है कि संपादक, संकलक और निष्पादन लक्ष्य
साथ काम कर रहे हैं।

```bhash
फलन मुख्य() -> शून्य {
    लिखो("मेरी कार्यसूची");
}
```

`फलन` किसी नाम से किया जाने वाला काम बताता है। `मुख्य` से पूरा
क्रमानुदेश शुरू होता है। `शून्य` बताता है कि फलन कोई मान वापस नहीं देता।
`लिखो` आउटपुट में पंक्ति भेजता है। उद्धरणों के भीतर का पाठ उसी तरह छपता है
जैसा आपने लिखा है। पूरा उदाहरण [hello.bhash](examples/hello.bhash) में है।

## कहाँ चलाएँ (Choose an environment)

- [Playground](https://play.bhashitva.org/) में पूरा उदाहरण चिपकाएँ। **पूरा क्रमानुदेश (Full program)** चुनें और **चलाएँ** दबाएँ। **सरल (Statements)** मोड में केवल `लिखो("मेरी कार्यसूची");` दें।
- [VS Code](../editors/vscode/README.md) में Bhash एक्सटेंशन और पूरा JDK 17+ स्थापित करें। फ़ाइल UTF-8 में `.bhash` विस्तार से सहेजें। **Bhash: Run Project or File** से पहले JVM चुनें।
- [Jupyter](../editors/jupyter/README.md) में भाष कर्नेल स्थापित करें और **Bhash (भाष)** चुनें। ऊपर का पूरा क्रमानुदेश एक कक्ष में चलाएँ। फिर अलग नोटबुक में [हिन्दी आरंभिक नोटबुक](../editors/jupyter/पहली-नोटबुक.ipynb) के कक्ष क्रम से चलाकर देखें कि घोषणाएँ उसी कर्नेल सत्र में कैसे बनी रहती हैं।

स्थानीय कमांड लाइन के लिए पूरा JDK 17+ और [पहले से बना भाष संकलक](https://github.com/bhashitva/bhash/releases/tag/bhash-0.22.0)
डाउनलोड करें। ऊपर का उदाहरण `hello.bhash` नाम से UTF-8 में सहेजें और उसी
फ़ोल्डर में निम्न आदेश चलाएँ। Maven केवल स्रोत से संकलक बनाने के लिए चाहिए।

```sh
java -jar bhash-compiler-0.22.0.jar run hello.bhash --target jvm
```

जब क्रमानुदेश को चलाते समय फ़ाइल का नाम या दूसरा तर्क देना हो, तो
`फलन मुख्य(तर्क: पाठ[]) -> शून्य` लिखें। तर्क सरणी में उसी क्रम से मिलते हैं
जिस क्रम में आप उन्हें देते हैं। [कमांड लाइन तर्क का उदाहरण](../docs/cli.md#command-line-arguments)
में पूरा क्रमानुदेश और चलाने के आदेश हैं।

## लक्ष्य का चुनाव (Compilation targets)

| लक्ष्य | कब चुनें |
| --- | --- |
| JVM | शुरू करने और कंसोल क्रमानुदेश चलाने के लिए। निर्माण हेतु पूरा JDK और बने JAR के लिए Java चाहिए। |
| .NET CLR | .NET वातावरण में चलाने के लिए। [स्थापना और लक्ष्य](../docs/clr-target.md) देखें। |
| Native | Linux x64, Windows x64 या Apple Silicon macOS के लिए मशीन कोड बनाने हेतु। [SDK निर्देश](../docs/managed-native-toolchain.md) देखें। |
| Browser WebAssembly | ब्राउज़र में चलने वाले उदाहरणों के लिए। [ब्राउज़र निर्माण](../docs/wasm-browser.md) देखें। स्थानीय फ़ाइल और डेटाबेस वाले उदाहरणों के लिए desktop लक्ष्य चुनें। |

## पहली त्रुटि पढ़ें (Diagnostics)

अर्धविराम हटा कर फिर चलाएँ। निदान में फ़ाइल, पंक्ति, स्तंभ और `BH…`
कोड देखें। त्रुटि अगले टोकन पर भी दिख सकती है। बताई जगह से एक पंक्ति पहले
देखना उपयोगी है। अर्धविराम वापस रखें और संदेश में अपना नाम लिखें।

हिन्दी टंकण में नुक़्ता और संयुक्त अक्षर अलग कीबोर्ड से अलग ढंग से आ सकते
हैं। [Unicode पहचानकर्ता मार्गदर्शिका](../tutorial/unicode-identifiers/README.md)
में समतुल्य वर्तनी और मान्य जोड़-चिह्न के उदाहरण हैं। पुराने स्रोत में
`कार्य` या पुराने `प्रत्येक` क्रम के लिए [वाक्यरचना बदलाव](../docs/hindi-syntax.md)
देखें।
