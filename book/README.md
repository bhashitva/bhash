# भाष में प्रोग्रामिंग (Programming with Bhash)

देवनागरी में अपना पहला क्रमानुदेश लिखने से लेकर जाँची हुई वेब सेवा चलाने तक
यह पुस्तक एक ही यात्रा दिखाती है। हम छोटी कार्यसूची से शुरू करेंगे। पहले
उसकी गणना और निर्णय लिखेंगे, फिर सूची और अभिलेख बनाएँगे, JSON में डेटा
लेंगे और अंत में उसे डेटाबेस वाली HTTP सेवा में बदलेंगे।

पहली बार प्रोग्रामिंग कर रहे हैं तो अध्याय क्रम से पढ़ें। हर अध्याय में
किसी परिणाम का पहले अनुमान लगाएँ, उदाहरण चलाएँ और फिर एक छोटा बदलाव करें।
दूसरी भाषा जानते हैं तो कोष्ठक में दिए अंग्रेज़ी नामों से परिचित अवधारणाएँ
पहचान सकते हैं। अभ्यास के उत्तर देखने से पहले अपने दो परीक्षण लिखें।
