# bhash-text-utils

Small Apache-2.0 source package demonstrating package publication and reuse.
`उपयोगीपाठ.अभिवादन(नाम)` returns a greeting. `उपयोगीपाठ.दोहराओ(संदेश, बार)`
returns text repeated 0–1000 times; invalid counts raise `अपवाद`.

यह Apache-2.0 उदाहरण संकुल प्रकाशन और पुनः उपयोग दिखाता है। `अभिवादन` नाम सहित
नमस्कार और `दोहराओ` पाठ की ०–१००० प्रतियाँ लौटाता है। गलत गिनती पर अपवाद मिलता है।
